## 一、产品概述

### 1.1 业务背景与问题陈述

SSMSBoostPlus 版本历史模块已能通过 `LocalHistoryDiffDialog` 做左右并排差异对比，差异行按 删除/新增/修改 着色并支持子词级高亮、同步滚动。但当前**缺少差异点导航能力**：

- 用户打开一个几百上千行的脚本对比时，差异行散布在长文本中，必须手动滚动、肉眼逐行寻找，效率极低；
- 在「紧急故障排查」场景（Persona 小王，见产品分析文档场景 A）下，能否在数秒内定位到"被误改的 WHERE 条件"直接关系到故障恢复时间（MTTR）；
- 既有产品分析文档第 303、483 行已明确：差异导航是 SSMSBoostPlus 相对 Redgate SQL Source Control / ApexSQL 的**最大交互差距**（`差异导航 ❌ 未实现`）。

本需求即补齐该能力：在对比弹窗提供「差异点快速定位」，支持自动跳转首个差异、上/下一个手动切换、差异计数与当前项高亮。

### 1.2 产品目标与成功标准（可量化）

| 目标 | 成功标准（可量化） |
|------|-------------------|
| 降低差异定位耗时 | 用户从打开对比到定位首个差异的平均操作步数 ≤ 1（自动跳转），手动切换单处差异 ≤ 2 次点击 |
| 缩短故障恢复时间 | 在「紧急故障排查」场景中，定位目标变更行耗时从「手动滚动（中位 30s+）」降至「≤ 3s」 |
| 缩小竞品差距 | 补齐"差异导航"能力，使差异对比交互矩阵中该项从 ❌ 变为 ✅ |
| 零学习成本 | 导航控件符合通用 diff 工具心智（上一处/下一处/计数），新用户无需引导即可使用 |

### 1.3 目标用户画像（Persona）

- **运维 DBA（小王）**：应急高频，最需要"秒级定位问题变更行"，P0 受益者。
- **数据库开发（小李）**：版本回溯时频繁对比多版差异，需要逐个差异点核查。
- （技术管理者老张：审计场景间接受益，本功能非其主诉求，不单列。）

### 1.4 核心使用场景

- **场景 A（紧急故障排查）**：打开对比 → 自动停在首个差异 → 逐处"下一个"核查 → 定位误改行。
- **场景 B（开发版本回溯）**：对比第 3 版与当前版 → 用"上/下一个"逐个浏览差异 → 复制所需片段。
- **场景 C（大脚本核查）**：数千行脚本仅几处差异 → 直接跳转，避免无效滚动。

## 二、用户故事与验收条件

> 格式：`作为<角色>，我希望<功能>，以便<价值>`；验收条件用 Given-When-Then。

### US-1（P0）自动跳转首个差异
- 作为运维 DBA，我希望打开差异对比后自动滚动并高亮到第一个差异行，以便我无需手动滚动就能立刻看到变更起点。
- 验收条件：
  - Given 对比内容存在 ≥1 处差异，When 弹窗完成渲染，Then 视图自动定位到首个差异行且该行处于高亮态。
  - Given 对比内容无任何差异，When 弹窗完成渲染，Then 不执行跳转、导航控件进入"无差异"禁用态、状态显示"差异 0 / 0"。

### US-2（P0）手动上一个/下一个切换
- 作为数据库开发，我希望通过"上一个/下一个"按钮在差异点间切换，以便逐处核查变更。
- 验收条件：
  - Given 当前在第 i 个差异（1≤i≤N），When 点击"下一个"，Then 跳转到第 i+1 个差异并高亮、状态更新为"i+1 / N"。
  - Given 当前在第 N 个差异，When 点击"下一个"，Then 按钮禁用、不越界。
  - Given 当前在第 1 个差异，When 点击"上一个"，Then 按钮禁用、不越界。
  - （边界策略：到达首/尾不循环回绕，按钮禁用，符合"可预测"原则。）

### US-3（P0）差异计数状态展示
- 作为任意用户，我希望看到"差异 X / Y"的计数，以便我知道当前位置与总差异数。
- 验收条件：
  - Given 存在 N 个差异，When 定位到第 i 个，Then 状态文本显示"差异 i / N"，且 i、N 实时同步。

### US-4（P0）当前差异点高亮
- 作为任意用户，我希望当前所在的差异行被明显高亮，以便与已读差异区分。
- 验收条件：
  - Given 切换前后差异点，When 跳转到新差异，Then 新行高亮、上一行恢复其原始差异底色（删/增/改对应的浅红/浅绿/浅黄），无残留高亮。
  - Given 左右两侧并排展示，When 定位某差异，Then 左、右两侧对应行同时高亮（差异在任一侧均可见）。

### US-5（P1）与同步滚动协同
- 作为数据库开发，我希望切换差异点时左右两侧保持对齐，以便对照理解。
- 验收条件：
  - Given 同步滚动开启，When 跳转到某差异，Then 两侧同时滚动到对应行并高亮。
  - Given 同步滚动关闭，When 跳转到某差异，Then 仅当前操作侧滚动定位，但两侧对应行均已高亮（仍可对照）。

### US-6（P2）重试后状态复位
- 作为任意用户，我希望加载失败重试成功后差异导航重新可用，以便重试不影响导航。
- 验收条件：
  - Given 用户点击重试并成功重新渲染，When 渲染完成，Then 差异列表重建、索引复位到首个差异（若有）、旧高亮清除。

## 三、功能规格说明

### 3.1 功能名称与概述
**差异点快速定位（Diff Navigation Bar）**：在 `LocalHistoryDiffDialog` 现有工具条（图例 + 同步滚动开关）区域增加导航控件组，含「上一个」「下一个」按钮与「差异 X / Y」状态文本；打开时自动定位首个差异并高亮。

### 3.2 触发条件与前置条件
- 触发：对比弹窗 `RenderDiff` 渲染完成（即 `SideBySideDiffBuilder.Diff` 产出对齐的左右行后）。
- 前置：差异行 = 左右任一侧 `ChangeType` 为 `Inserted/Deleted/Modified` 的行；两侧逐行对齐，第 i 个差异对应左右第 i 行配对。

### 3.3 正常流程（主流程）
1. 弹窗渲染完成 → 收集差异点列表（配对左右 Paragraph 引用）。
2. 若差异数 N > 0：索引置 0，自动滚动并高亮首个差异，状态"差异 1 / N"，启用上/下按钮（"上一个"因在首部禁用）。
3. 用户点"下一个"/"上一个" → 索引 ±1 → 还原上一高亮 → 新行高亮 → 滚动到位 → 状态更新。

### 3.4 异常流程（错误处理、边界情况）
- **无任何差异（N=0）**：禁用上/下按钮，状态"差异 0 / 0"，不跳转、不高亮。
- **仅 1 个差异（N=1）**：状态"1/1"，上/下按钮均禁用（不循环）。
- **重试加载（LeftRetry/RightRetry）**：`RenderDiff` 重建文档 → 差异列表重建、索引复位、旧高亮清除；成功后再按正常流程定位。
- **加载失败遮罩（Overlay 显示）**：重试前不收集差异；重试成功后收集。
- **空文档（(empty)）**：按无差异处理。

### 3.5 交互说明
- 位置：建议置于 Row 1 工具条，与"图例""同步滚动"同条（左：导航；中：图例；右：同步滚动），不新增整行以最小化布局扰动。
- 按钮样式复用既有 `ToolbarButton`（注意：按钮用 `Button` 样式，`ToggleButton` 需专用样式，见技术约束提醒）。
- 状态文本随切换实时刷新。

### 3.6 数据规则
- 差异计数 = 对齐行中"左或右任一为变更行"的行数。
- 当前索引 0-based，展示为 1-based。

### 3.7 权限要求
- 无额外权限要求（与现有对比弹窗一致）。

## 四、数据埋点与指标

| 行为事件 | 说明 | 用途 |
|----------|------|------|
| DiffNav_Open_AutoJump | 打开时自动跳转首个差异 | 衡量自动跳转使用率 |
| DiffNav_Next / DiffNav_Prev | 手动切换次数 | 衡量导航活跃度 |
| DiffNav_DiffCount | 每次对比的差异总数分布 | 衡量典型差异规模 |

## 五、非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 跳转/高亮为本地 UI 操作，响应 ≤ 100ms；大脚本（>10,000 行）不卡顿（依赖既有渲染，不在本需求范围做虚拟化） |
| 兼容性 | 与现有 SSMS 22 / net472 / WPF 渲染一致；不引入新第三方依赖 |
| 可访问性 | 按钮具备 ToolTip 与禁用态视觉（Opacity 0.4），状态文本清晰可读 |
| 一致性 | 视觉与交互风格沿用现有对比弹窗（ToolbarButton、图例配色） |

## 六、验收标准

### 6.1 核心功能验收清单
- [ ] 打开含差异的对比，自动定位并高亮首个差异
- [ ] "差异 X / Y"计数正确实时更新
- [ ] "上一个/下一个"在差异点间正确切换、边界禁用、不越界
- [ ] 当前差异点高亮，切换时旧高亮还原、无残留
- [ ] 左右两侧对应差异行同步高亮

### 6.2 异常场景验收清单
- [ ] 无差异时按钮禁用、显示"差异 0 / 0"、不高亮
- [ ] 仅 1 差异时上/下均禁用
- [ ] 重试成功后导航复位且可用
- [ ] 同步滚动开/关下跳转行为符合 US-5

### 6.3 性能指标验收标准
- [ ] 跳转/高亮响应 ≤ 100ms（人工感知无延迟）
- [ ] 大脚本下不引入明显卡顿
