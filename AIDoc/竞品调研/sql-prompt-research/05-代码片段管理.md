# 05 - 代码片段管理

## 一、功能概述

SQL Prompt 的代码片段系统允许用户快速插入预定义的 SQL 代码模板，支持内置片段和用户自定义片段，通过**占位符系统**实现灵活的代码插入和光标定位。

---

## 二、功能细节

### 2.1 内置片段

SQL Prompt 提供丰富的内置代码片段模板，涵盖常见的 T-SQL 编程模式：

| 类别 | 示例 |
|------|------|
| 基础查询 | SELECT、INSERT、UPDATE、DELETE 模板 |
| 控制流 | IF/ELSE、WHILE、TRY/CATCH、BEGIN/END 模板 |
| 高级模式 | CTE、Cursor、临时表、表变量模板 |
| DDL | CREATE TABLE、CREATE INDEX、CREATE PROCEDURE 模板 |

### 2.2 自定义片段

通过 **Snippet Manager** 创建和管理自定义片段：

- 定义片段的**触发文本**（如输入 `sel` 触发 SELECT 模板）
- 编写片段内容（SQL 代码模板）
- 使用占位符实现智能插入

### 2.3 占位符系统

| 占位符 | 功能 |
|--------|------|
| `$SELECTEDTEXT$` | 将选中的代码插入到片段中 |
| `$CURSOR$` | 片段插入后光标定位位置 |
| `$DATE$` / `$TIME$` | 插入当前日期/时间 |
| `$DBNAME$` | 插入当前数据库名称 |
| `$SERVER$` | 插入当前服务器名称 |
| `$USER$` | 插入当前用户名 |

### 2.4 代码片段重构

选中一段代码后，通过片段系统可以快速包裹代码：

| 片段 | 效果 |
|------|------|
| 选中 + `be` | 包裹为 BEGIN...END 块 |
| 选中 + `ifs` | 包裹为 IF 块 |
| 选中 + `tc` | 包裹为 TRY...CATCH 块 |
| 选中 + `cte` | 转为 CTE 表达式 |

### 2.5 团队共享

- 自定义片段存储在文件系统中
- 可将片段文件夹放到共享位置
- 团队所有成员引用同一文件夹
- 更新共享片段后其他成员自动生效

## 三、技术原理推测

### 3.1 片段系统架构

```
┌──────────────────────────────────────────────────┐
│                 Snippet Manager                    │
├──────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌──────────────────────┐   │
│  │  内置片段库       │  │  用户自定义片段库      │   │
│  │  (预设模板)       │  │  (.snippet 文件)      │   │
│  └────────┬────────┘  └──────────┬───────────┘   │
│           │                      │                │
│           └──────────┬───────────┘                │
│                      ↓                            │
│             ┌────────────────┐                    │
│             │   片段引擎       │                    │
│             │  - 触发匹配     │                    │
│             │  - 占位符替换   │                    │
│             │  - 文本插入     │                    │
│             └────────────────┘                    │
└──────────────────────────────────────────────────┘
```

### 3.2 片段匹配机制

- 用户输入触发文本（如 `sel`）
- 引擎在片段库中查找匹配的触发文本
- 显示候选列表（如果多个匹配）
- 用户选择后，引擎执行占位符替换并插入代码

### 3.3 片段文件格式推测

```json
{
  "name": "SELECT Template",
  "trigger": "sel",
  "description": "Basic SELECT query",
  "category": "Query",
  "body": [
    "SELECT $CURSOR$",
    "FROM $table$",
    "WHERE $condition$"
  ]
}
```

## 四、用户体验亮点

1. **即输即用**：输入几个字母即可展开完整模板
2. **智能包裹**：选中代码后一键套用模板
3. **光标导航**：使用占位符定义插入后光标位置
4. **团队一致**：共享片段保证团队使用相同的代码模板

## 五、可实现的借鉴方案

### 5.1 技术路线

| 步骤 | 内容 | 关键实现 |
|------|------|---------|
| 1 | 设计片段数据模型 | JSON/YAML 格式，包含 name、trigger、body、placeholders |
| 2 | 实现片段引擎 | 触发拦截 → 占位符解析 → 文本替换 → 插入编辑器 |
| 3 | 构建 Snippet Manager UI | 可视化管理界面，支持 CRUD 操作 |
| 4 | 实现团队共享 | 文件系统共享 + 定期同步 |

### 5.2 片段的 SSMS 集成方式

- 监听编辑器输入，匹配触发文本
- 通过 `ITextEdit` / `ITextBuffer.Insert` 插入片段内容
- 使用 `ITextCaret` 定位光标到 `$CURSOR$` 位置

### 5.3 最小可行实现

```
阶段1（基础）：
  - 10-20 个内置基础片段
  - 简单触发文本匹配
  - 无占位符（纯文本插入）

阶段2（增强）：
  - 占位符系统（$CURSOR$, $SELECTEDTEXT$）
  - 自定义片段管理 UI
  - 代码包裹功能

阶段3（高级）：
  - 团队共享
  - 片段同步
  - 智能片段推荐
```
