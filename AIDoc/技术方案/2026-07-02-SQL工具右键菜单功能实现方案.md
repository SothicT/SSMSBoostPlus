# SQL工具右键菜单功能实现方案

## 功能概述

### 功能1：关键词查询
- 用户在 SQL 编辑器中选择关键词
- 右键菜单 → "关键词查询"
- 打开一个新的查询编辑器，预填充按关键词搜索数据库中对象的 SQL 语句

### 功能2：打开脚本
- 用户在 SQL 编辑器中选择对象名称（存储过程/函数/视图/表等）
- 右键菜单 → "打开脚本"
- 从数据库获取对象的完整定义脚本
- 在新的查询编辑器中打开
- 性能要求：1-2秒内完成（含5K行脚本）

## 实现方案

### 架构设计

两个功能都遵循 SSMSBoostPlus 现有的命令模式：

```
User 右键菜单点击
    ↓
WpfContextMenuService.OnCommandBarButtonClick (DTE CommandBar 事件)
    ↓
ExecuteVsCommand (通过 IVsUIShell 执行 VSCT 命令)
    ↓
Command.ExecuteAsync (命令处理)
    ↓
SsmsEditorService (获取选中文本、连接信息)
    ↓
DatabaseService (执行SQL查询)
    ↓
DTE.ItemOperations.NewFile (打开新查询编辑器)
```

### 命令定义

| 命令 | ID | 菜单文字 | 说明 |
|------|-----|---------|------|
| 关键词查询 | 0x0205 | 🔍 关键词查询 | 按选中关键词搜索对象 |
| 打开脚本 | 0x0206 | 📄 打开脚本 | 获取选中对象的定义脚本 |

### 关键词查询的SQL生成

根据选中的关键词，生成如下SQL：

```sql
-- 关键词查询: {keyword}
SELECT 
    SCHEMA_NAME(schema_id) AS [架构],
    name AS [对象名称],
    type_desc AS [对象类型],
    create_date AS [创建时间],
    modify_date AS [修改时间]
FROM sys.objects
WHERE type IN ('U', 'V', 'P', 'FN', 'IF', 'TF', 'TR')
  AND name LIKE '%{keyword}%'
ORDER BY type_desc, name;
```

### 打开脚本的获取策略

1. **代码对象（存储过程/函数/视图/触发器）**：
   - 查询 `sys.sql_modules.definition`（最快，直接返回 NVARCHAR(MAX)）
   - 该字段存储完整 CREATE 语句，5000行脚本可在毫秒级返回

2. **表对象**：
   - 查询 `INFORMATION_SCHEMA.COLUMNS` 获取列信息
   - 查询 `sys.indexes` 获取索引信息
   - 动态生成 CREATE TABLE 语句
   - 注意：表脚本生成较复杂，允许稍长时间

3. **性能保障**：
   - 使用单一 SqlConnection，避免重复连接开销
   - 设置 CommandTimeout = 5 秒
   - 对象不存在时给出明确提示

### 右键菜单注册

沿用现有的 DTE CommandBars 动态注册方式：
1. 在 `WpfContextMenuService` 中添加新命令到 `AiCommands` 列表
2. 使用 `Controls.Add(Type.Id)` 方法添加菜单项
3. 通过 `CommandBarButton.Click` 事件路由到 VSCT 命令处理器

## 最终实现方案（关键词查询）

1. 选中关键词 → 右键 → "关键词查询"
2. SSMS 右下角弹出 **小型进度提示弹窗**（SearchProgressPopup，深色无边框，含进度条）
3. 后台打开新查询窗口 → 自动填充搜索 SQL → 自动执行 F5
4. 查询结果直接显示在 **SSMS 标准结果网格**中
5. 进度弹窗自动关闭（或 10 秒超时自动关闭）

### 进度弹窗设计
- 尺寸：320×64，无边框深色主题
- 含 🔍 图标 + 状态文字 + 不确定进度条
- 自动定位在 SSMS 窗口右下角
- 10 秒超时自动关闭（防遗忘）
