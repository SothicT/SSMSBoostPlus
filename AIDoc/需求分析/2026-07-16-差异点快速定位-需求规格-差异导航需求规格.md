# 需求规格文档：版本历史差异对比 — 差异点快速定位

> 本文档由 Common-BA 基于 PRD（SPEC 来源）拆解，仅定义"做成什么样"，不含技术方案。技术方案由 Architect 在 G3 阶段产出。

## 一、需求概述

- **业务背景**：版本历史差异对比弹窗已支持行级+子词级高亮与同步滚动，但缺少差异点导航，长脚本下用户需手动滚动查找差异，效率低。
- **核心目标**：在对比弹窗提供"差异点快速定位"——打开自动跳转首个差异、上/下一个手动切换、差异计数、当前差异高亮。
- **适用角色**：运维 DBA、数据库开发（见 PRD Persona）。
- **关联模块**：`LocalHistoryDiffDialog`（差异对比弹窗）；依赖既有 `RenderDiff` 渲染产出。
- **影响范围**：仅对比弹窗 UI 与交互；不影响版本历史列表、回滚、同步滚动等其它能力。

## 二、整体功能架构

```
LocalHistoryDiffDialog（差异对比弹窗）
└── 差异导航条（本期新增）
    ├── 自动跳转：渲染完成后定位并高亮首个差异
    ├── 手动切换：上一个 / 下一个 按钮
    ├── 计数状态：差异 X / Y 文本
    └── 当前高亮：当前差异行（左右两侧）高亮 + 切换还原
```

## 三、详细功能需求

### 3.1 差异导航条（Diff Navigation Bar）

- **功能描述**：在对比弹窗现有工具条区域（图例 + 同步滚动开关同条）新增导航控件组，含「上一个」「下一个」两个按钮与一个「差异 X / Y」状态文本。
- **触发条件**：`RenderDiff` 渲染完成（左右两侧差异内容就绪）。
- **前置条件**：差异点 = 对齐行中"左或右任一为变更行（Inserted/Deleted/Modified）"的行；两侧逐行对齐，第 i 个差异对应左右第 i 行配对。

#### 3.1.1 自动跳转首个差异
- 渲染完成且差异数 N > 0 时，视图自动定位到第 1 个差异行，该行处于高亮态，状态文本显示"差异 1 / N"。
- N = 0 时，不跳转、不高亮，导航控件进入"无差异"禁用态，状态显示"差异 0 / 0"。

#### 3.1.2 手动上一个 / 下一个
- 点击「下一个」：当前索引 +1，跳转到新差异并高亮，状态更新；位于最后一个差异时按钮禁用、不越界。
- 点击「上一个」：当前索引 -1，跳转到新差异并高亮，状态更新；位于第一个差异时按钮禁用、不越界。
- 边界策略：**到达首/尾不循环回绕**，对应按钮禁用（可预测原则）。

#### 3.1.3 差异计数状态
- 状态文本实时显示"差异 i / N"（i 为 1-based 当前位置，N 为差异总数），随切换同步更新。

#### 3.1.4 当前差异高亮
- 定位到某差异时，该差异对应行（左、右两侧）均高亮。
- 切换差异点时，先还原上一个高亮行的原始底色（新增=浅绿 / 删除=浅红 / 修改=浅黄），再高亮新行，**无残留高亮**。

### 3.2 与同步滚动协同
- 同步滚动开启：跳转某差异时，左右两侧同时滚动到对应行并高亮。
- 同步滚动关闭：跳转时仅当前操作侧滚动定位，但两侧对应行均已高亮（仍可对照）。

### 3.3 重试后状态复位
- 加载失败遮罩下不收集差异；点击重试并成功重新渲染后，差异列表重建、索引复位到首个差异（若有）、旧高亮清除，导航恢复可用。

## 四、权限管控需求

- 本需求**不引入新权限**；交互权限与现有对比弹窗一致（任何可打开对比弹窗的角色均可使用导航）。

## 五、数据字段需求

- **无数据库表 / 字段变更**。
- 仅涉及对比弹窗运行时内存态（如当前差异索引、差异总数），属实现细节，由 Developer 在实现时定义，不在本需求规格约束范围。
- 若本期实现埋点（见 PRD 第四章），`DiffNav_*` 事件仅写入应用日志，不新增持久化存储。

## 六、非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 跳转/高亮为本地 UI 操作，人工感知响应 ≤ 100ms；不引入新第三方依赖 |
| 兼容性 | 与现有 SSMS 22 / net472 / WPF 渲染一致 |
| 可访问性 | 按钮具备 ToolTip 与禁用态视觉（Opacity 0.4），状态文本清晰可读 |
| 一致性 | 视觉与交互风格沿用现有对比弹窗（按钮样式、图例配色），不新增整行布局 |

## 七、研发注意事项与风险提示

- **易错逻辑**：差异点配对必须基于"左右逐行对齐"——第 i 个差异对应左右第 i 行，不能各自独立计数（否则左右计数/跳转不一致）。
- **易遗漏场景**：重试重新渲染后必须重建差异列表并复位索引与高亮，否则会引用失效的旧 Paragraph 或显示错误计数。
- **残留高亮**：切换时必须先还原上一高亮行的原始底色，避免多行叠加高亮。
- **新旧兼容**：仅修改 `LocalHistoryDiffDialog` 两个文件，不影响其它模块；回退风险低。
- **范围边界**：忽略空白/注释、键盘快捷键、三路合并、差异块缩略图**不在本期**（见 PRD 第八章），BA 不额外补充。
