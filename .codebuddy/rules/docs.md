# 文档约定

## 输出目录

**默认输出目录**：`AIDoc/`

无指定路径时，所有文档统一输出到此目录。

## 目录结构

```
AIDoc/
├── 项目文档/          # 项目内部文档（长期文档，无日期前缀）
├── 竞品调研/          # 竞品分析报告（编号+标题）
├── 需求分析/          # 需求分析文档（日期前缀）
├── 技术方案/          # 技术设计方案（日期前缀）
├── 架构变更/          # 架构调整文档（日期前缀）
├── 诊断报告/          # 问题诊断报告（日期前缀）
├── 构建分析/          # 构建问题分析（日期前缀）
├── 部署方案/          # 部署相关文档（日期前缀）
├── 错误自动诊断/      # 错误诊断功能文档
├── 周报/              # 项目周报
└── API文档/           # 接口文档
```

## 命名规范

### 日期格式

所有带日期的文档统一使用 **`YYYY-MM-DD-` 前缀**格式（禁止后缀或 `YYYYMMDD` 格式）。

```
✅ 2026-06-09-CLI换行符转义修复方案.md
❌ CLI换行符转义修复方案-2026-06-09.md    （日期在后缀）
❌ 20260609-164500-CLI换行符转义修复方案.md  （无连字符+时间戳）
```

### 按文档类型的命名规则

| 文档类型 | 命名格式 | 示例 |
|----------|----------|------|
| 项目文档 | `{项目名}-文档类型.md`（长期文档，无日期） | `SSMSBoostPlus-开发文档.md` |
| 竞品调研 | `{编号}-{主题}.md` | `01-智能代码补全.md` |
| 需求分析 | `YYYY-MM-DD-{主题}.md` | `2026-06-09-AI对话面板设计方案.md` |
| 技术方案 | `YYYY-MM-DD-{主题}.md` | `2026-06-14-功能性增强方案.md` |
| 架构变更 | `YYYY-MM-DD-{主题}.md` | `2026-06-04-AI子项目拆分方案.md` |
| 诊断报告 | `YYYY-MM-DD-{主题}.md` | `2026-06-07-SSMS22连接提供者全部失败.md` |
| 构建分析 | `YYYY-MM-DD-{主题}.md` | `2026-06-04-pkgdef-ctmenu差异对比报告.md` |
| 部署方案 | `YYYY-MM-DD-{主题}.md` | `2026-06-04-SSMS22插件部署方案.md` |
| 周报 | `周报-{起始日期}至{结束日期}.md` | `周报-2026-06-02至2026-06-09.md` |
| 索引文件 | `README.md`（保持不变） | `诊断报告/README.md` |

## 文档头部

每个文档应包含头部元信息：

```markdown
---
title: 文档标题
date: 2026-06-07
author: AI Assistant
tags: [tag1, tag2]
---
```

## 文档内容规范

| 要求 | 说明 |
|------|------|
| 标题层级 | 最多 3 级（## / ### / ####） |
| 代码块 | 必须标注语言 | ```csharp |
| 表格 | 优先使用表格整理结构化数据 |
| 图片 | 使用相对路径，存放在文档同目录下 |

## 文档维护

| 操作 | 要求 |
|------|------|
| 新增文档 | 按上述目录结构放置 |
| 更新文档 | 更新头部 `date` 字段 |
| 删除文档 | 从目录结构中移除 |
