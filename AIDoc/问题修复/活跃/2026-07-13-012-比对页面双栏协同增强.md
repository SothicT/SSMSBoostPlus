# 版本历史比对页面双栏协同增强（差异标记 + 滚动同步）

> 合并自 #008（差异未标记） + #009（滚动同步）
> 合并原因：两者都涉及比对页面左右双栏的协同体验，差异标记完成后可为滚动同步提供按差异行对齐跳转的能力

## 现象

### 场景 A：差异未标记（原 #008）
版本历史比对页面，左侧服务器当前定义脚本和右侧历史版本以纯文本并排显示，差异完全不标记，用户需肉眼逐行比对，效率极低。

### 场景 B：滚动不同步（原 #009）
左侧服务器当前定义脚本和右侧历史版本各自独立滚动、互不影响，用户比对时需手动同步两侧滚动位置，操作繁琐。

**期望行为**：差异行高亮底色标注 + 差异字符变色（新增绿色、删除红色、修改黄色）+ 行号旁标记图标（+/-/~），滚动任意一侧时另一侧自动跟随到相同行号位置，保留手动开关按钮（默认开启同步）。

## 需求澄清

- **用户场景**：用户打开版本历史比对页面，审查服务器当前定义与历史版本的差异
- **验收标准**：
  1. 差异行以高亮底色标注，一眼可定位所有变更行
  2. 差异字符变色：新增绿色、删除红色、修改黄色
  3. 行号旁标记 + / - / ~ 图标
  4. 滚动任意一侧另一侧自动跟随，行号精确对齐
  5. 提供同步开关按钮，默认开启，用户可随时关闭独立滚动
  6. 差异标记完成后，滚动同步可优先对齐到差异行
- **范围边界**：仅限当前比对页面的左右双栏（左侧服务器定义 vs 右侧历史版本）

## 子任务拆分

1. 差异计算引擎：使用 DiffPlex 计算左右文本差异
2. 差异行底色标注 + 差异字符变色渲染
3. 行号旁标记图标（+/-/~）
4. 滚动同步：监听一侧滚动事件 → 计算对应行号 → 同步另一侧滚动位置
5. 同步开关按钮 UI（默认开启）
6. 差异行跳转联动（差异标记完成后，滚动同步可优先对齐差异行）

## 根因
`LocalHistoryDiffDialog` 使用纯 TextBox 显示脚本，完全不进行差异计算和标记，且左右面板无滚动同步，用户需肉眼逐行比对、手动同步滚动。

## 影响范围
版本历史比对页面（`LocalHistoryDiffDialog`）的左右双栏显示区域。

## 涉及模块
`src/SSMS/UI/VersionHistory/LocalHistoryDiffDialog.xaml`、`LocalHistoryDiffDialog.xaml.cs`

## 诊断记录
- `TextBox` 不支持富文本，无法进行差异高亮渲染
- 无 DiffPlex 集成，差异完全不标记
- 左右面板各自独立滚动，无同步机制

## 修复方案
1. XAML：TextBox → RichTextBox + ScrollViewer 命名（LeftScroller/RightScroller），绑定 ScrollChanged 事件
2. XAML：图例栏新增滚动同步 ToggleButton（🔗 同步滚动 / 🔓 独立滚动）
3. Code-behind：集成 DiffPlex SideBySideDiffBuilder，构建 FlowDocument 渲染差异行
4. 差异行：底色（绿/红/黄）+ 词级 SubPieces 变色 + 行号旁 +/-/~ 标记
5. 滚动同步：按比例同步垂直+水平滚动，`_scrollSyncing` 防重入 + `_scrollSyncEnabled` 开关
