# SSMSBoostPlus 功能性增强方案

> 基于 SQL Prompt / dbForge SQL Complete 竞品调研，结合项目现状制定的功能增强路线图。

## 一、当前功能现状

| 功能模块 | 当前状态 | 竞品对标 |
|----------|----------|----------|
| AI 建议/注释/格式化/性能分析 | ✅ 已实现 | SQL Prompt AI 辅助 |
| AI 对话面板（ToolWindow） | ✅ 已实现 | SQL Prompt Prompt AI |
| Version Guard（版本拦截） | ✅ 已实现 | 无对标（独创） |
| 智能代码补全 | ❌ 无 | SQL Prompt 核心功能 |
| 代码片段管理 | ❌ 无 | SQL Prompt Snippets |
| Tab History | ❌ 无 | SQL Prompt Tab History |
| SQL 重构 | ❌ 无 | SQL Prompt Smart Rename 等 |
| 批量格式化 | ❌ 无 | dbForge 批量处理 |

## 二、增强方案（按优先级排序）

### P0 - 高价值核心功能

#### 1. 代码片段管理（Snippets）

| 维度 | 说明 |
|------|------|
| **现状** | 无 |
| **差距** | SQL Prompt 有完整片段系统（占位符、Tab 跳转） |
| **价值** | 常用语句一键插入，高频刚需场景 |
| **难度** | 低（纯本地逻辑，无 SSMS 编辑器深度集成依赖） |
| **建议优先级** | **#1**（投入小、见效快） |

**MVP 功能范围**：

- 内置常用片段（SELECT/INSERT/UPDATE/DELETE 模板、常用 CTE、临时表等）
- 用户自定义片段（JSON 格式，支持变量占位符 `$1`, `$2`...）
- 菜单/快捷键触发片段选择器
- 片段导入/导出（JSON 文件，支持团队共享）

**技术方案**：

```
src/
├── Core/
│   ├── Interfaces/ISnippetService.cs      # 片段服务接口
│   ├── Models/Snippet.cs                  # 片段模型
│   └── Services/SnippetService.cs         # 片段加载/保存/搜索
└── SSMS/
    ├── Commands/SnippetCommand.cs          # 插入片段命令
    └── UI/Snippets/SnippetPicker.xaml      # 片段选择器 UI
```

**数据格式**：

```json
{
  "name": "SELECT TOP",
  "shortcut": "selt",
  "description": "SELECT TOP N 查询模板",
  "body": "SELECT TOP($1$) $2$\nFROM $3$\nWHERE $4$",
  "category": "DML"
}
```

#### 2. 智能代码补全（IntelliSense）

| 维度 | 说明 |
|------|------|
| **现状** | 仅有 AI 分析能力，无实时补全 |
| **差距** | SQL Prompt 有完整的上下文感知补全（表名→列名→JOIN） |
| **价值** | 用户最直接感知的效率提升，插件核心竞争力 |
| **难度** | 高（需 T-SQL 解析器 + SSMS 编辑器集成） |
| **建议优先级** | **#4**（价值最高但投入大，可分期做） |

**分期实施路线**：

| 阶段 | 范围 | 技术依赖 |
|------|------|----------|
| 阶段1 | FROM 后表名补全 | T-SQL 轻量解析器 + INFORMATION_SCHEMA |
| 阶段2 | 表名后列名补全 + 排序 | Schema 缓存 + LRU 历史权重 |
| 阶段3 | JOIN 补全 + 函数签名 | 完整 AST 解析 + 外键关系推断 |
| 阶段4 | 存储过程参数 + 链接服务器 | 深度元数据查询 |

**关键技术选型**：

| 组件 | 方案 | 说明 |
|------|------|------|
| T-SQL 解析 | Microsoft.SqlServer.TransactSql.ScriptDom（项目已有引用） | 官方解析器，语法覆盖全 |
| 编辑器集成 | MEF `ICompletionSourceProvider` | VS Shell 标准扩展点 |
| 元数据缓存 | 内存 Dictionary + 后台刷新 | 参考 SQL Prompt 架构 |
| 候选排序 | LRU 权重 + 类型匹配权重 | `score = (isRecent?100:0) + (isTypeMatch?50:0) + alphaScore` |

> 详细方案参考：`AIDoc/竞品调研/sql-prompt-research/09-智能代码补全实现方案.md`

### P1 - 高价值增强功能

#### 3. Tab History（查询历史）

| 维度 | 说明 |
|------|------|
| **现状** | 无 |
| **差距** | SQL Prompt 有完整的 Tab History |
| **价值** | 意外关闭后可恢复，查看历史查询，解决用户痛点 |
| **难度** | 低 |
| **建议优先级** | **#2** |

**功能范围**：

- 自动保存每个查询 Tab 的内容（SQLite 本地存储）
- 按 SSMS 重启后提示恢复未保存的查询
- 历史列表：按时间/数据库/关键字筛选
- 支持收藏/固定常用查询

**技术方案**：

```
src/
├── Core/
│   ├── Interfaces/IQueryHistoryService.cs
│   ├── Models/QueryHistoryEntry.cs
│   └── Services/QueryHistoryService.cs      # SQLite 存储
└── SSMS/
    ├── Services/TabMonitorService.cs         # 监听 DTE Document 事件
    └── UI/History/QueryHistoryWindow.cs      # ToolWindow 展示历史
```

**存储设计**：

```sql
CREATE TABLE QueryHistory (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    Content TEXT NOT NULL,
    DatabaseName TEXT,
    ServerInstance TEXT,
    CreatedAt DATETIME NOT NULL,
    IsPinned INTEGER DEFAULT 0,
    SourceTab TEXT
);
```

#### 4. AI 对话面板增强

| 维度 | 说明 |
|------|------|
| **现状** | 内存会话，关闭 SSMS 后清空；纯文本渲染 |
| **可增强** | 会话持久化、Markdown 渲染、流式输出 |
| **难度** | 中 |
| **建议优先级** | **#3** |

**增强项按优先级**：

| 序号 | 增强项 | 价值 | 难度 |
|------|--------|------|------|
| 1 | 会话持久化（JSON 文件） | 避免丢失对话上下文 | 低 |
| 2 | 流式输出对接 | 体验提升显著 | 中 |
| 3 | Markdown 渲染 | 代码块高亮、表格美化 | 中 |
| 4 | Prompt 自定义 | 高级用户需求 | 低 |
| 5 | 深度上下文注入（schema/索引） | AI 分析更精准 | 高 |

### P2 - 中等价值功能

#### 5. 批量格式化

| 维度 | 说明 |
|------|------|
| **现状** | 只能格式化当前编辑器 |
| **差距** | SQL Prompt / dbForge 支持批量处理 |
| **价值** | 团队代码规范统一 |
| **难度** | 中（需文件选择 UI） |

**功能范围**：

- 选择目录/文件列表 → 批量格式化
- 支持格式化风格配置
- 格式化预览 + 确认

---

#### 6. 深度上下文注入

| 维度 | 说明 |
|------|------|
| **现状** | AI 请求仅传 databaseName |
| **可增强** | 自动注入 schema、索引信息、执行统计 |
| **价值** | AI 分析更精准，减少用户手动粘贴 |
| **难度** | 高（需元数据查询 + Token 预算管理） |

**上下文注入层次**：

| 层级 | 内容 | 触发条件 |
|------|------|----------|
| L1 | 数据库名 | 当前已实现 |
| L2 | 选中 SQL 涉及的表结构 | 自动检测 |
| L3 | 相关索引信息 | 性能分析时自动注入 |
| L4 | 执行计划 | AIPerformanceCommand 已部分实现 |

|------|------|------|------|

## 四、与竞品差异化定位

| 维度 | SQL Prompt | dbForge | **SSMSBoostPlus** |
|------|-----------|---------|-------------------|
| AI 能力 | 基础（Prompt AI） | 无 | **深度融合**（建议/注释/格式化/性能/对话） |
| 价格 | $210/年 | $129.95/年 | **免费开源** |
| Version Guard | 无 | 无 | **独创功能** |
| 补全 | 行业领先 | 最全面 | 规划中 |
| 本地化 | 英文 | 英文 | **中文优先** |

**核心差异化**：AI 深度融合 + Version Guard + 免费开源 + 中文优先
