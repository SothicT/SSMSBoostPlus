# 技术方案：版本历史差异对比 — 差异点快速定位

- 规格依据：`AIDoc/需求分析/2026-07-16-差异点快速定位-需求规格-差异导航需求规格.md`（SPEC-SSMSBP-DIFFNAV-001）
- 方案类型：轻量级技术方案（功能迭代，单模块 2 文件，无 DB / 无新接口）
- 输出格式：Architect 格式 B

---

## 一、变更概述

- **变更范围**：仅 `LocalHistoryDiffDialog.xaml` 与 `LocalHistoryDiffDialog.xaml.cs` 两个文件。
- **影响模块**：版本历史差异对比弹窗（`LocalHistoryDiffDialog`）。
- **技术目标**：在弹窗工具条新增"差异导航条"，实现自动跳转首个差异、上/下手动切换、差异计数、当前差异高亮；不改变既有差异计算（DiffPlex SideBySide）、着色与同步滚动逻辑。
- **设计原则**：最小化改动、复用既有样式与渲染产物（FlowDocument 的 Paragraph 引用）、不引入新依赖。

## 二、现有代码事实（设计依据）

- `RenderDiff(leftText, rightText)`：`SideBySideDiffBuilder.Diff(...)` 产出 `diffModel.OldText.Lines`（左）与 `diffModel.NewText.Lines`（右），**两列表等长、逐行对齐**。
- `BuildDocument(lines, ...)`：按 `lines` 顺序为每行创建一个 `Paragraph` 加入 `FlowDocument.Blocks`；故 `Blocks[i]` 对应 `lines[i]`。
- 变更行（`Inserted/Deleted/Modified`）的 `Paragraph.Background` 已被设为对应浅色底（增绿/删红/改黄）；`Imaginary` 行为对齐占位（非真实差异）；`Unchanged` 为白底。
- 滚动容器：`LeftScroller` / `RightScroller`，`OnScrollChanged` 在 `_scrollSyncEnabled` 时按偏移比例镜像另一侧（已有 `_scrollSyncing` 重入保护，且仅在 `ExtentHeightChange==0` 时同步）。
- 既有按钮均为 `Button` + `ToolbarButton` 样式（安全；注意不要用 ToggleButton 配 Button 样式，见 2026-07-16 版本历史页签崩溃修复）。

## 三、关键设计决策

### 3.1 差异点数据结构
- 新增私有结构 `DiffRow`，持有当前差异行在左、右两侧的 `Paragraph` 引用，以及采集时两侧的原始 `Background` 画刷（用于高亮还原）。
- 新增实例字段：
  - `List<DiffRow> _diffRows`：差异点集合（按行序）。
  - `int _currentDiffIndex = -1`：当前差异索引（-1 表示无）。

### 3.2 差异点采集（在 RenderDiff 内、文档赋值后）
- 取 `LeftViewer.Document.Blocks.OfType<Paragraph>()` 与 `RightViewer.Document.Blocks.OfType<Paragraph>()` 为有序列表（与 `lines` 同序）。
- 遍历行索引 `i`：若 `leftLines[i].Type` 或 `rightLines[i].Type` ∈ {`Inserted`, `Deleted`, `Modified`}，则将该行作为一个差异点加入 `_diffRows`，并**在加入时快照**两侧 `Paragraph.Background` 存入 `DiffRow.LeftOrigBg / RightOrigBg`（`Imaginary` 行不参与，避免把占位行算作差异）。
- 采集后清空旧的 `_currentDiffIndex = -1`、`_diffRows` 先重建（保证重试/重渲染后引用有效、计数正确）。

### 3.3 跳转与滚动定位（GoToDiff）
- 入参目标索引 `idx`（0-based，范围 0..N-1，越界忽略）。
- 步骤：
  1. 若 `_currentDiffIndex >= 0`，将 `_diffRows[_currentDiffIndex]` 的左右 `Paragraph.Background` 还原为各自 `LeftOrigBg / RightOrigBg`（**高亮还原，防残留**）。
  2. 将 `_diffRows[idx]` 左右 `Paragraph.Background` 设为高亮画刷 `DiffHighlightBg`（建议浅蓝 `#BBDEFB`，与增/删/改底色明显区分）。
  3. 对 `_diffRows[idx]` 的左右 `Paragraph` 分别调用 `BringIntoView()`，使两侧均滚动到该差异行。
  4. 更新 `_currentDiffIndex = idx`，刷新计数状态文本。
- **滚动可靠性（PRD/BA 风险点）**：`BringIntoView()` 会沿视觉树向上找到最近的 `ScrollViewer` 并滚动到该行，对长文档同样有效；同步滚动开启时，左侧 `BringIntoView` 触发 `OnScrollChanged` 自动镜像右侧，右侧再 `BringIntoView` 与之同位置，整体收敛、无抖动。对超长脚本如需"居中"体验，可后续用 `VisualTreeHelper` 计算偏移后 `ScrollToVerticalOffset`，但本期以 `BringIntoView` 为充分方案，不增加复杂度。
- **自动跳转（打开即定位）**：`RenderDiff` 采集完成后，若 `_diffRows.Count > 0`，调用 `GoToDiff(0)`。因构造期窗口可能尚未布局，`BringIntoView` 在 `Loaded` 事件后再补一次（若 `_currentDiffIndex==0` 且窗口未布局），确保首屏即定位；高亮（Background）不依赖布局，构造期即生效。

### 3.4 上 / 下一个切换
- `GoPrev()`：`if (_currentDiffIndex > 0) GoToDiff(_currentDiffIndex - 1);` 否则按钮禁用。
- `GoNext()`：`if (_currentDiffIndex >= 0 && _currentDiffIndex < _diffRows.Count - 1) GoToDiff(_currentDiffIndex + 1);` 否则按钮禁用。
- **边界不循环**：到首/尾仅禁用对应按钮，不回绕（符合 BA 3.1.2）。
- 按钮 `IsEnabled` 随 `_currentDiffIndex` 与 `_diffRows.Count` 实时更新（含 N=0 / N=1 场景）。

### 3.5 计数状态
- 状态文本：`差异 {_currentDiffIndex + 1} / {_diffRows.Count}`；N=0 时显示 `差异 0 / 0` 并禁用两按钮。

### 3.6 UI 布局（XAML）
- Row 1 工具条由现有 2 列改为 3 列：`[导航控件] [图例] [同步滚动]`。
- 导航控件：水平 `StackPanel`，含 `上一个`（`Button`+`ToolbarButton`）、`TextBlock` 计数、 `下一个`（`Button`+`ToolbarButton`）；`Click` 绑定 `GoPrev` / `GoNext`。
- 视觉与既有工具条一致（复用 `ToolbarButton`、`ToolbarButton` 按钮样式安全；不引入 `ToggleButton` 配 Button 样式的错误）。

### 3.7 重试复位
- `LeftRetryButton_Click` / `RightRetryButton_Click` 均重新调用 `RenderDiff`；`RenderDiff` 内部先重建 `_diffRows`、重置 `_currentDiffIndex`、再采集并自动跳转，天然满足 BA AC-DIFFNAV-006（重建+复位+清旧高亮）。

## 四、接口与数据变更

- **无新增对外接口**；内部仅新增私有方法 `GoToDiff(int)` / `GoPrev()` / `GoNext()` 与私有采集逻辑（属实现细节，由 Developer 落地）。
- **无数据库表 / 字段 / 缓存变更**（与 BA 声明一致）。

## 五、影响评估与兼容性

- 仅改动差异对比弹窗；不影响版本历史列表、回滚、同步滚动、重载逻辑。
- 既有 `OnScrollChanged` 同步逻辑无需修改（程序化 `BringIntoView` 借助其完成镜像）。
- 回退风险低：仅 2 文件，可单独回退。

## 六、风险提示与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| `BringIntoView` 在超长脚本下定位体验（仅置顶不居中） | 低 | 本期以置顶为可接受；居中为后续增强，不阻塞 |
| 重试后引用失效/计数错误 | 低 | 每次 `RenderDiff` 重建 `_diffRows` 并快照原底色，旧引用不复用 |
| 高亮残留（多行叠加） | 低 | 切换前先还原上一行原底色，再设新行高亮 |
| 程序化滚动触发同步死循环 | 低 | 既有 `_scrollSyncing` 重入保护 + `ExtentHeightChange==0` 判定；两侧对齐同位置收敛 |
| 误用 ToggleButton 配 Button 样式致 XAML 加载崩溃 | 低 | 导航按钮用 `Button` + `ToolbarButton`，遵循 2026-07-16 已修复的 TargetType 约束 |

## 七、研发注意事项

- 差异点配对必须基于"左右逐行对齐"（第 i 个差异 = 左右第 i 行），**禁止左右各自独立计数**（否则两侧跳转/计数错位）。
- `Imaginary` 行是占位、非真实差异，采集时排除。
- 高亮画刷须与增/删/改底色可区分，避免用户混淆"当前项"与"差异类型"。
- 编码后须按 BA 的 6 条 AC 做 G4 自测 + G5 验收；Tester 重点验证无差异、单差异、首尾边界、高亮还原、重试复位。
