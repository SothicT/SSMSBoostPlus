## 二、完成事项详述

### 2.1 🧱 基础设施：编译部署链路修复（06-02 ~ 06-04）

| 问题 | 根因 | 修复 |
|------|------|------|
| SSMS 22 顶栏菜单不显示 | 三层嵌套：pkgdef GUID 不一致 → CTO 未嵌入 → SSMS 跳过 PkgDef 重新扫描 | `CreatePkgDef.exe` 手动生成 + `ssms.exe /setup` 强制刷新 |
| .pkgdef 编译不生成 | .NET SDK 10 的 `PrepareForRunDependsOn` 覆盖 VSSDK 生成链 | 新增 `ManualPkgDef` 目标，`AfterTargets="Build"` 执行 CLI |
| SSMS 自定义安装路径检测失败 | `SmartAssemblyLoader` 硬编码路径 + 大小写不匹配 | 策略0：从程序集反向推导；`IndexOf(OrdinalIgnoreCase)` 解决大小写 |
| CodeBuddy CLI 找不到 | 路径仅用户 PATH 且 .cmd 无法直接 Process.Start | 系统 PATH 兜底 + cmd.exe /c fallback + 配置化 CLI 路径 |

**交付物**：
- `deploy-to-ssms.bat` 更新（优先 bin\Release 找 pkgdef）
- `build-and-deploy` Skill 新增 Step 3.5 手动生成 pkgdef/cto

### 2.2 🤖 AI 能力建设（06-04 ~ 06-09）

#### 2.2.1 AI 桥接层架构重构
- 新建 `src/AI/` 独立项目（Bridge / Context / Interfaces / Models / Parsing / Prompts）
- 新建 `src/Shared/` 共享项目（Constants、StringExtensions、FormatStyle）
- 双 Provider 架构：`CodebuddyCliBridge`（CLI）+ `AIApiClientBridge`（HTTP API）
- `BridgeFactoryService` DI 集成 + `ILoggerService` 注入

#### 2.2.2 AI 对话面板（ToolWindow）⭐ 本周重点
- WPF 可停靠面板（`Ctrl+Shift+K`），SQL 专家模式
- 交互模式：自由对话 + 快捷指令（智能建议/添加注释/格式化/性能分析）
- AI 回答中的 SQL 代码块自动提取 + **Diff 确认后替换编辑器**
- 架构：`ChatSessionService`（Core）+ `AIChatControl`（WPF）+ `AIChatToolWindow`（VS SDK）
- 编译修复：XAML MC3089 / CS1061 / ToolWindow COMException

#### 2.2.3 AI Bridge 日志增强
- Bridge 层统一注入 `ILoggerService`，覆盖 CLI 和 HTTP 两个桥接
- 日志格式：请求 Prompt + 响应内容（截断 2000 chars）+ Token 用量 + 耗时
- 影响文件：2 个 Bridge 实现 + BridgeFactoryService + BridgeFactory + 6 处调用点

#### 2.2.4 AI 配置增强
- `IsAIConfiguredAsync()` CLI 优先检测（`codebuddy --version`），无需 ai-config.json
- `AIConfiguration` 模型新增 `CodebuddyCliPath` 可配字段
- AI 配置对话框 UI 分区：CLI / HTTP API / 高级设置
