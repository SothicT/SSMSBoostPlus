一、作品概述

SSMSBoostPlus 是一款面向 SQL Server 开发人员与 DBA 的 SSMS 22 扩展插件（VSIX），全程由 CodeBuddy AI Agent 驱动开发。项目以版本管控与AI 辅助 SQL 审查为核心，内置六大功能模块，将数据库元数据（Schema、索引、执行计划）深度注入 AI 上下文，实现精准的 SQL 分析与版本防护。

3.1 清晰的协作链路图

本项目定义了完整的 Agent Team 协作体系，五角色分工、六阶段推进、五道门控，确保 AI 在每个阶段都有明确定位，人类在关键决策点介入。

PM 产品经理→ BA 需求分析师→ Architect 架构师→ Developer 工程师→ Tester 测试工程师→ 小H 发布部署
阶段 1: 产品定义

PM Agent 输出 PRD + 竞品分析 + 路线图，用户审核通过门控 G1 后进入需求分析

阶段 2: 需求分析

BA Agent 拆解需求、定义字段规格、标注验收条件，通过门控 G2

阶段 3: 技术设计

Architect Agent 技术选型、接口设计、数据模型，通过门控 G3

阶段 4-5: 开发与测试

Developer Agent 编码 + TDD，Tester Agent 独立验证，通过门控 G4/G5

先定义规范标准，再 Coding

项目启动阶段即通过 AI Agent 定义了完整的开发规范体系（7 个 Rules 文件，存放于 .codebuddy/rules/，每次会话自动加载）：

规范文件覆盖内容价值
architecture.md单向依赖链、模块职责边界、CodeAnalysisService 位置、BridgeFactory 路由策略、接口化原则、Prompt 模板策略杜绝循环依赖，模块边界清晰，AI 不会写出架构不当的代码
build.md编译命令（.slnx 而非 .sln）、项目结构目标框架、PkgDef 手动生成机制、NuGet 配置、SSMS 内部 DLL 引用规则避免构建链路踩坑，每次编译 AI 都知道正确的命令和注意事项
code-style.mdC# 命名规范、XAML 行为库（禁止 System.Windows.Interactivity）、配置与日志路径、异常处理模式、async/await 规范代码风格统一，Code Review 零沟通成本
deploy.md部署脚本、目标目录、部署清单（核心 DLL + 第三方依赖 + PkgDef）、部署流程、故障排查AI 发布部署不踩坑，全流程自动化
docs.mdAIDoc 目录结构、命名规则（日期前缀等）、文档头部格式、文档维护规范93 篇文档格式一致，可追溯、可检索
test.md测试门禁、技术栈（xUnit/Moq/FluentAssertions）、命名规范（方法名_场景_预期）、新增测试要求103 个测试用例风格统一，提交前强制通过
team-collaboration-rules.mdc五角色定义、六阶段协作、五道门控、通信矩阵、质量门控、文档管理、Agent 使用指引Agent Team 自动按流程协作，不跳过关键步骤

3.2 人工评审→迭代改进 真实案例

以下展示一个典型的「AI 生成 → 人类发现缺陷 → 诊断工具定位 → AI 修复 → 人体验证」闭环案例。

场景：版本历史页签打开后永久显示"正在加载版本历史..."，核心功能不可用。

轮次阶段内容
1 AI 生成代码 Developer Agent 完成 LocalHistoryToolWindow 的 WPF UI 实现，包括 PinButton（钉住按钮）使用 ToggleButton 控件，并引用了 ToolbarButton 样式。
2 人工评审发现 用户部署后打开版本历史面板，始终显示占位文本，真控件未能创建。用户反馈问题截图。
3 error-diagnosis 诊断 Agent 读取 Serilog 日志（ssmsboostplus-2026071617.log），发现 XamlParseException: "Button"TargetType 与元素"ToggleButton"的类型不匹配，自动定位到 LocalHistoryToolWindowControl.xaml:260-264，确定 ToggleButton 引用了 TargetType="Button" 的样式导致 WPF 运行时崩溃。
4 AI 修复 Agent 提出两套方案：（A）新增 TargetType="ToggleButton" 的样式 ToolbarToggleButton；（B）将控件改为 Button。推荐方案 A（语义正确+选中态反馈），用户确认后 Agent 执行修复。
5 人体验证 编译→部署→打开版本历史面板，正常展示版本列表与差异对比，Bug 关闭。

工具用途
