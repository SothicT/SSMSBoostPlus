# 版本差异对比弹窗·复制 SQL 按钮 需求规格

> 角色：Common-BA（主 Agent 兼任）｜阶段：BA 需求分析（G2 门控前产物）
> 复杂度判定：**轻量级**（单控件新增 + 单事件处理），采用 BA 轻量级格式 A。
> 范围边界（来自 PRD G1 结论）：本版本仅新增 1 个【复制 SQL】按钮，复制右侧历史脚本；不纳入"复制当前/仅复制差异/导出文件"。

## 1. 需求概述
- 功能目标：在 `LocalHistoryDiffDialog` 底部按钮栏新增【复制 SQL】按钮，一键将右侧历史脚本（`_historicalScript`）复制到系统剪贴板，缩短"看到差异→拿走脚本"的路径。
- 影响范围：仅 `src/SSMS/UI/VersionHistory/LocalHistoryDiffDialog.xaml` 与同名 `.xaml.cs` 两个文件；不影响现有【在编辑器中打开】【关闭】。
- 关联模块：版本历史（VersionHistory）差异对比弹窗。

## 2. 功能细则
- 触发条件：用户点击【复制 SQL】按钮。
- 前置条件：弹窗已加载，且 `_historicalScript` 非空（为空时按钮禁用）。
- 核心业务规则：
  - 点击后将 `_historicalScript` 全文写入剪贴板（`System.Windows.Clipboard.SetText`）。
  - 复制成功后按钮文案切为"✅ 已复制"，2 秒后复原为"复制 SQL"（自包含反馈，无需外部 Toast/StatusBar）。
  - 复制失败（剪贴板被锁/异常）时按钮文案切为"复制失败"，2 秒后复原，并记录日志，不崩溃、不阻塞弹窗。
- 页面细则（XAML）：在 Row 3 的 `<StackPanel Orientation="Horizontal" HorizontalAlignment="Right">` 内、现有 `CloseButton` 之前（其左侧）新增按钮，右对齐布局与现状一致。
  - 建议定义：
    ```xml
    <Button x:Name="CopySqlButton" Content="复制 SQL"
            Style="{StaticResource PrimaryButton}"
            Width="100" Margin="0,0,8,0" Click="CopySqlButton_Click"/>
    ```
- 代码细则（.xaml.cs）：新增 `CopySqlButton_Click` 事件处理方法（见第 4 节异常处理代码骨架）。

## 3. 数据规则
- 无数据库/接口字段变更。
- 数据来源：弹窗私有字段 `_historicalScript`（= 构造入参 `rightScript`，右侧/历史版本脚本）。
- 复制内容：`_historicalScript` 全文（含换行），不截断、不加工。
- 兼容性：保持与现有 `OpenInEditorButton_Click` 使用同一份 `_historicalScript`，语义一致。

## 4. 异常处理
- 空脚本：构造/加载时 `CopySqlButton.IsEnabled = !string.IsNullOrEmpty(_historicalScript)`；点击时再次 `if (string.IsNullOrEmpty(_historicalScript)) return;` 双保险（与 `OpenInEditorButton_Click` 的空脚本保护同源）。
- 剪贴板锁定 / `Clipboard.SetText` 抛异常：`try/catch` 捕获，按钮文案临时切"复制失败"，2s 复原，并通过 `_logger.Error(ex, "[LocalHistory] 复制 SQL 到剪贴板失败")` 记录。
- 线程：Click 事件运行于 UI 线程（STA），`Clipboard.SetText` 可直接调用，无需 `Dispatcher.Invoke`。
- 禁用 DTE：复制仅操作剪贴板，严禁调用 DTE（避免模态对话框内 ExecuteCommand 死锁，与现有 OpenInEditor 的"延迟执行"原则一致）。
- 建议代码骨架：
  ```csharp
  private void CopySqlButton_Click(object sender, RoutedEventArgs e)
  {
      if (string.IsNullOrEmpty(_historicalScript)) return;
      try
      {
          System.Windows.Clipboard.SetText(_historicalScript);
          CopySqlButton.Content = "✅ 已复制";
          var timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(2) };
          timer.Tick += (_, _) => { CopySqlButton.Content = "复制 SQL"; timer.Stop(); };
          timer.Start();
      }
      catch (Exception ex)
      {
          _logger.Error(ex, "[LocalHistory] 复制 SQL 到剪贴板失败");
          CopySqlButton.Content = "复制失败";
          var timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(2) };
          timer.Tick += (_, _) => { CopySqlButton.Content = "复制 SQL"; timer.Stop(); };
          timer.Start();
      }
  }
  ```
  > 注：`DispatcherTimer` 位于 `System.Windows.Threading`，若文件未引用需 `using System.Windows.Threading;`。

## 5. 权限管控需求
- 无角色权限差异；任何能打开差异对比弹窗的用户均可使用。
- 无权限受限场景。

## 6. 非功能需求
- 性能：复制动作同步执行，万行级脚本为字符串拷贝，反馈 <200ms。
- 兼容性：SSMS 22 宿主（net472），WPF/STA 原生支持剪贴板。
- 日志：失败时经既有 `_logger` 记录，便于排查。
- 容错：任何异常均被捕获，弹窗不崩溃、其余按钮可用。

## 7. 研发注意事项与风险提示
- 复用既有模式：项目内 `AIStreamResultDialog.CopyCodeButton_Click`（Clipboard.SetText + 按钮文案 + DispatcherTimer）与 `LocalHistoryToolWindowControl`（Clipboard.SetText + UpdateStatus）已是成熟写法，本功能对齐前者（弹窗无 StatusBar）。
- 最小化修改：仅新增 1 按钮 + 1 事件方法 + 1 处禁用态初始化；不改动 `OpenInEditorButton_Click`、`CloseButton_Click`、渲染、导航等任何既有逻辑。
- 反馈一致性：采用按钮内文案切换，而非新增全局 Toast 组件，降低改动面。
- 禁用态时机：`_historicalScript` 在构造函数内已赋值（`_historicalScript = rightScript ?? ""`），可在 `InitializeComponent()` 后于构造函数或 `OnDialogLoaded` 设置按钮 `IsEnabled`。
