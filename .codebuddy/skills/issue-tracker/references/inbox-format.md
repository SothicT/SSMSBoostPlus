# 待处理问题箱格式说明

收件箱是问题追踪的入口，人工维护，拆分后标记 `- [x]` 保留条目。

## 格式

```markdown
# 待处理问题箱

## 待处理

- [ ] [高] [Bug] 历史版本检索失败 — 对象标识符带架构限定符导致匹配失败
- [ ] [紧急] [Bug] 用户数据脱敏逻辑失效 — 敏感信息未被正确遮盖
- [ ] [中] [优化] 编辑器字体渲染异常 — 某些 DPI 下字体模糊
- [ ] [高] [新需求] 版本历史页签增加数据库名列 — 下拉框只加载当前库的对象历史记录
```

## 规则

- 每行一个待处理问题，使用 `- [ ]` 复选框标记。
- 格式：`- [ ] [优先级] [类型] 简短描述 — 补充说明`
- 优先级标注为可选前缀 `[紧急|阻断|高|中|低]`，省略时默认 `中`。
- 类型标签为可选前缀 `[Bug|新需求|优化]`，省略时默认 `Bug`。
- 描述格式：`简短描述 — 补充说明`，`—` 为全角破折号（也支持半角 `--`）。
- 拆分后对应条目标记为 `- [x]`，行尾追加 `（已拆分于 YYYY-MM-DD）`，保留条目与结构。
- 已关闭/已归档的问题不入收件箱。

## 优先级定义

| 优先级 | 含义 | 排序 |
|--------|------|------|
| 紧急 | 线上问题、安全漏洞、数据损坏，需立即处理 | 0（最高） |
| 阻断 | 核心功能无法使用 | 1 |
| 高 | 重要功能异常但非阻断 | 2 |
| 中 | 一般问题（默认） | 3 |
| 低 | 优化/改进建议 | 4 |

## 类型定义

| 类型 | 含义 |
|------|------|
| Bug | 功能异常/缺陷 |
| 新需求 | 新增功能/增强 |
| 优化 | 改进建议/体验优化 |
