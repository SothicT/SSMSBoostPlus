## 问题现象

1. 进入比对页面 → 所有同步按钮堆在第一行
2. 点击同步 → 恢复按钮也在第一行
3. 多个差异块 → 按钮缺失或错位

## 根因分析

### 根因 1（主因）：`PopulateActionStrip()` 在 `DiffContentGrid` 折叠状态下调用

**代码位置**：`AIDiffDialog.xaml.cs` 第 347-348 行 + 第 431 行 + 第 452-454 行

```csharp
// 构造函数（第 347-348 行）
LoadingOverlay.Visibility = Visibility.Visible;
DiffContentGrid.Visibility = Visibility.Collapsed;  // ← 内容区被折叠

// OnLoaded → Phase 2b（第 431 行）
PopulateActionStrip();  // ← 此时 DiffContentGrid 仍然 Collapsed！

// OnLoaded → Phase 4（第 452-454 行）
LoadingOverlay.Visibility = Visibility.Collapsed;
DiffContentGrid.Visibility = Visibility.Visible;  // ← 太晚了，按钮已经创建完毕
```

**WPF 行为**：当元素 `Visibility = Collapsed` 时，该元素及其所有子元素**不参与布局**，尺寸为 0×0。此时调用 `RichTextBox.UpdateLayout()` 不会产生有效布局，`GetCharacterRect()` 对所有段落返回 `Rect(0, 0, 0, 0)`。

**结果**：所有按钮的 `Canvas.SetTop(button, 0)` → 全部堆在第一行。

### 根因 2（级联）：`_syncButtonClickedTop` 记录了错误的 Y 坐标

**代码位置**：`SyncBlock_Click` 第 1631-1634 行

```csharp
double bt = Canvas.GetTop(button);  // ← button 的 Top 是 0（根因 1 导致）
_syncButtonClickedTop[hunkIndex] = bt;  // ← 记录了 0
```

由于同步按钮初始位置就是 Y=0（根因 1），点击时记录的 `_syncButtonClickedTop` 也是 0。同步后恢复按钮使用这个记录值 → 也在第一行。

### 根因 3（级联）：`_syncButtonClickedTop` 在多次同步后过时

当用户先同步 Hunk A、再同步 Hunk B 时：
- 同步 A 时记录 `_syncButtonClickedTop[A] = Y_A`（正确）
- 同步 B 时插入了新段落 → Hunk A 的恢复按钮实际 Y 位置已偏移
- 但 `_syncButtonClickedTop[A]` 仍是旧值 `Y_A` → A 的恢复按钮错位

### 根因 4：`PositionActionButtons()` 是死代码

**代码位置**：第 1332-1366 行

`PositionActionButtons()` 方法定义了 Canvas 高度同步和滚动位置同步逻辑，但**从未被调用**（在之前的重构中，`PopulateActionStrip` 不再调用它）。

**结果**：
- `ActionStripCanvas.Height` 从未被设置 → Canvas 高度仅为按钮的包围盒高度
- 操作条 ScrollViewer 的 `ExtentHeight` 过小 → 滚动同步无效
- 按钮无法在滚动时保持与文档对齐

### 根因 5：窗口缩放/文本回流时按钮不会重新定位

当前没有 `SizeChanged` 或 `LayoutUpdated` 处理器来在窗口缩放导致段落高度变化时重新定位按钮。

## 修复方案

### 修复 1：将 `PopulateActionStrip()` 移到 `DiffContentGrid` 可见之后

**文件**：`AIDiffDialog.xaml.cs`
**位置**：`OnLoaded` 方法，第 428-454 行

```csharp
// ===== 修改前 =====
if (!_isLoaded) return;

// Phase 2b: 填充中间操作条
PopulateActionStrip();  // ← DiffContentGrid 还是 Collapsed

// Phase 2c: 初始行号编号
...

// Phase 4: Show content, hide loading
LoadingOverlay.Visibility = Visibility.Collapsed;
DiffContentGrid.Visibility = Visibility.Visible;

// ===== 修改后 =====
if (!_isLoaded) return;

// Phase 2c: 初始行号编号（不依赖布局，可在折叠状态下执行）
_isProgrammaticChange = true;
try
{
    RenumberRightParagraphs();
}
finally
{
    _isProgrammaticChange = false;
}

// Phase 3: Setup navigation and scrolling
LeftViewer.AddHandler(ScrollViewer.ScrollChangedEvent,
    new ScrollChangedEventHandler(OnScrollChanged));
RightViewer.AddHandler(ScrollViewer.ScrollChangedEvent,
    new ScrollChangedEventHandler(OnScrollChanged));

UpdateDiffNavigation();

// Phase 4: Show content FIRST, then populate buttons
LoadingOverlay.Visibility = Visibility.Collapsed;
DiffContentGrid.Visibility = Visibility.Visible;

// Phase 4b: 等 WPF 完成布局后再填充操作条
// 必须在 DiffContentGrid 可见后调用，否则 GetCharacterRect 返回 0
Dispatcher.BeginInvoke(new Action(() =>
{
    if (!_isLoaded) return;
    PopulateActionStrip();
}), System.Windows.Threading.DispatcherPriority.Render);
```

**修改 `PopulateActionStrip` 第二步**（第 1282-1325 行）：恢复按钮也使用 `GetCharacterRect`
```csharp
// 第二步：为 _hunkInsertedBlocks 中已同步的 hunk 创建恢复按钮
foreach (var kvp in _hunkInsertedBlocks)
{
    int hunkIdx = kvp.Key;
    var syncState = kvp.Value;

    int blockIndex;
    if (syncState.Inserted.Count > 0)
        blockIndex = syncState.Inserted.First();
    else
        blockIndex = syncState.OrigStart;

    if (_actionButtons.ContainsKey(blockIndex)) continue;

    var para = GetParagraphAtIndex(RightViewer.Document, blockIndex);
    if (para == null) continue;

    var button = CreateUndoButton(hunkIdx);
    double buttonTop = 0;
    try
    {
        var rect = para.ContentStart.GetCharacterRect(LogicalDirection.Forward);
        buttonTop = rect.Top;
        if (double.IsNaN(buttonTop) || double.IsInfinity(buttonTop)) buttonTop = 0;
    }
    catch { }

    _actionButtons[blockIndex] = button;
    ActionStripCanvas.Children.Add(button);
    Canvas.SetLeft(button, 2);
    Canvas.SetTop(button, buttonTop);
}
```

### 修复 3：复活 `PositionActionButtons()`，用于同步 Canvas 高度 + 重新定位所有按钮

**文件**：`AIDiffDialog.xaml.cs`
**位置**：第 1328-1366 行

```csharp
/// <summary>
/// 同步 Canvas 高度/滚动位置，并重新定位所有按钮。
/// 在 PopulateActionStrip 之后异步调用，确保 GetCharacterRect 返回准确坐标。
/// 也在 OnScrollChanged 和 SizeChanged 时调用。
/// </summary>
private void PositionActionButtons()
{
    if (!_isLoaded || _isPositioningButtons) return;

    _isPositioningButtons = true;
    Dispatcher.BeginInvoke(new Action(() =>
    {
        try
        {
            if (!_isLoaded) return;

            RightViewer.UpdateLayout();
            LeftViewer.UpdateLayout();

            // 1. 同步 Canvas 高度与文档内容高度
            var rightSv = FindScrollViewer(RightViewer);
            if (rightSv != null)
            {
                ActionStripCanvas.Height = Math.Max(rightSv.ExtentHeight, rightSv.ViewportHeight);
                ActionStripScroller.ScrollToVerticalOffset(rightSv.VerticalOffset);
            }

            // 2. 重新定位所有按钮（使用最新的 GetCharacterRect）
            var blockSnapshot = RightViewer.Document.Blocks.OfType<Paragraph>().ToList();
            for (int i = 0; i < blockSnapshot.Count; i++)
            {
                if (_actionButtons.TryGetValue(i, out var button))
                {
                    try
                    {
                        var rect = blockSnapshot[i].ContentStart.GetCharacterRect(LogicalDirection.Forward);
                        double top = rect.Top;
                        if (double.IsNaN(top) || double.IsInfinity(top)) top = 0;
                        Canvas.SetTop(button, top);
                    }
                    catch { }
                }
            }
        }
        catch (Exception ex)
        {
            System.Diagnostics.Debug.WriteLine($"PositionActionButtons failed: {ex}");
        }
        finally
        {
            _isPositioningButtons = false;
        }
    }), System.Windows.Threading.DispatcherPriority.Render);
}
```

### 修复 4：在 `PopulateActionStrip` 末尾调用 `PositionActionButtons()`

**文件**：`AIDiffDialog.xaml.cs`
**位置**：`PopulateActionStrip` 方法末尾（第 1326 行 `}` 之前）

```csharp
    // 在 PopulateActionStrip 末尾添加：
    
    // 异步重新定位所有按钮（确保布局完成后再设置准确的 Y 坐标）
    PositionActionButtons();
}  // PopulateActionStrip 结束
```

**说明**：`PopulateActionStrip` 中的 `GetCharacterRect` 提供初始位置，`PositionActionButtons` 在 Render 优先级再次校正，双保险。

### 修复 5：添加 `SizeChanged` 处理器，窗口缩放时重新定位按钮

**文件**：`AIDiffDialog.xaml.cs`
**位置**：`OnLoaded` 方法中，Phase 3 之后

```csharp
// Phase 3: Setup navigation and scrolling
LeftViewer.AddHandler(ScrollViewer.ScrollChangedEvent,
    new ScrollChangedEventHandler(OnScrollChanged));
RightViewer.AddHandler(ScrollViewer.ScrollChangedEvent,
    new ScrollChangedEventHandler(OnScrollChanged));

// ★ 新增：窗口缩放时重新定位按钮
RightViewer.SizeChanged += (s, e) => PositionActionButtons();
```
