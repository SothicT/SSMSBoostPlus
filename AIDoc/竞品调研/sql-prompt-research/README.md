## 一、产品定位

SQL Prompt 是 **Redgate Software** 开发的 SQL Server 智能代码辅助插件，深度集成于 **SSMS** 和 **Visual Studio** 中，属于 Redgate **SQL Toolbelt Essentials** 套件的核心组件。

**核心价值主张**：通过智能代码补全、代码质量分析、SQL 格式化和数据库对象导航等功能，帮助 SQL Server 开发者提高编写效率和代码质量。

## 四、技术架构概览

```
┌─────────────────────────────────────────────────────────┐
│                    SSMS / Visual Studio                   │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────┐    │
│  │              SQL Prompt 插件层                     │    │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │    │
│  │  │ 补全引擎  │ │ 格式化引擎│ │ 代码分析引擎      │ │    │
│  │  └────┬─────┘ └────┬─────┘ └────────┬─────────┘ │    │
│  │  ┌────┴────────────┴───────────────┴─────────┐  │    │
│  │  │          元数据缓存层（内存）                  │  │    │
│  │  │  - 按需加载 schema                           │  │    │
│  │  │  - 多数据库缓存不卸载                         │  │    │
│  │  │  - 排除策略 + 手动刷新                       │  │    │
│  │  └──────────────────────┬─────────────────────┘  │    │
│  └─────────────────────────┼────────────────────────┘    │
│                            ↓                             │
│               SQL Server / Azure SQL                     │
└─────────────────────────────────────────────────────────┘
```

### 关键架构特点

1. **单进程内存缓存**：所有 schema 按需加载到内存，同一会话不卸载
2. **进度对话框反馈**：大型数据库加载时显示进度，不阻塞 UI
3. **排除策略**：支持按服务器/数据库/Schema 排除对象，支持通配符
4. **手动刷新为主**：`Ctrl+Shift+D` 刷新，实验性自动刷新可选
5. **AI 调用走云端**：Prompt AI 请求附带 Schema 信息发送到 Redgate 云服务

## 五、竞品格局

### 主要竞品对比

| 维度 | **SQL Prompt** | **dbForge SQL Complete** | **ApexSQL Complete** |
|------|---------------|-------------------------|---------------------|
| **代码补全** | 14/20 项 | 20/20 项（最全面） | 11/20 项 |
| **SQL 格式化** | 155 选项 | 更丰富（含批量） | 不支持 |
| **代码重构** | 4/5 项 | 5/5 项 | 不支持 |
| **T-SQL 调试器** | 无 | 有（独占） | 无 |
| **AI 功能** | 有（Prompt AI） | 无 | 无 |
| **价格** | **$210/年** | $129.95/年 | $567/年 |
| **产品状态** | 活跃开发 | 活跃开发 | 2025/12/31 停止支持 |

### 竞争分析要点

- **SQL Prompt 优势**：品牌认知度高、跨对象重构（Smart Rename/Split Table）、AI 功能加持
- **dbForge SQL Complete 优势**：功能更全面（补全/格式化/调试器）、性价比更高、批量处理能力强
- **ApexSQL Complete**：已淘汰，不具备对比价值
