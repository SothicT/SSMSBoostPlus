## 1. 架构概览

### 1.1 系统上下文

当前主文件 `SqlTemplateCompletionService.cs`（~3185行）承担了补全引擎的所有职责：输入事件处理、文本分析、别名解析、字段查询、弹窗渲染。本次重构将其拆分为多个专注模块：

### 1.2 架构原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个模块只做一件事：断句、定位、解析、分发 |
| **无状态化** | 语句断句器/语法定位器为纯函数，输入文本→输出结果 |
| **向后兼容** | 现有空格触发、点号触发、快捷键行为不变 |
| **增量替换** | 不重写整个文件，用新模块逐步替代旧逻辑 |
| **可测试性** | 核心算法模块纯逻辑，不依赖 SSMS/WPF |

## 2. 模块详细设计

### 2.1 SqlBreaker（语句断句器）

**职责**：从文本缓冲区中定位光标所在的完整 SQL 语句。

**文件**：新增 `src/SSMS/Services/SqlBreaker.cs`

**接口定义**：

```csharp
/// <summary>
/// SQL 语句断句器。从文本缓冲区定位光标所在的完整 SQL 语句。
/// </summary>
public class SqlBreaker
{
    /// <summary>
    /// 从光标位置找到其所属的完整 SQL 语句。
    /// </summary>
    /// <param name="snapshot">ITextSnapshot 或 string[] lines</param>
    /// <param name="caretPosition">光标在文本中的绝对位置</param>
    /// <returns>当前语句的起始行号、结束行号、语句文本</returns>
    public (int startLine, int endLine, string statementText) LocateCurrentStatement(
        ITextSnapshot snapshot, int caretPosition);

    /// <summary>
    /// 从字符串文本中判断一条 SQL 语句的起始关键词。
    /// </summary>
    public StatementType DetectStatementType(string statementText);
}

public enum StatementType
{
    Select, Insert, Update, Delete, Merge, Exec, DDL, Unknown
}
```

**SQL 起始关键词列表**（用于向前/向后搜索语句边界）：

```
顶层起始关键词（按优先级）：
  优先级 1：SELECT / UPDATE / DELETE / INSERT / MERGE / EXEC / CREATE / ALTER / DROP
  优先级 2：WITH（向前搜索最近的 SELECT/UPDATE/DELETE 作为 CTE 主体）

语句结束条件：
  遇到下一个同层起始关键词（在相同嵌套层级，不在子查询/括号内）
  遇到 GO（行首，大小写不敏感）
  缓冲区末尾
```

**断句算法**（伪代码）：

```
function LocateCurrentStatement(snapshot, caretPos):
    // Phase 1: 向前搜索语句起始
    startLine = caretLine
    for line = caretLine down to 0:
        lineText = snapshot[line]
        if lineText matches 顶层起始关键词 (且不在字符串/注释内):
            keywordPos = find position of keyword in lineText
            if this is the closest keyword above or at caretLine:
                startLine = line
                break
        if lineText matches GO (行首):
            // GO 之前是前一条语句，startLine = GO 的下一行
            startLine = line + 1
            break

    // Phase 2: 向后搜索语句结束
    endLine = caretLine
    nestingDepth = 0
    for line = caretLine to snapshot.LineCount - 1:
        lineText = snapshot[line]
        nestingDepth += count '(' in lineText (跳过字符串/注释)
        nestingDepth -= count ')' in lineText (跳过字符串/注释)
        if nestingDepth == 0 AND lineText matches 另一条顶层起始关键词:
            endLine = line - 1
            break
        if lineText matches GO (行首):
            endLine = line - 1
            break
    endLine = min(endLine, snapshot.LineCount - 1)

    // Phase 3: 提取语句文本
    statementText = extract text from startLine to endLine
    return (startLine, endLine, statementText)
```

**关键设计决策**：
- 嵌套深度跟踪：用 `(` 和 `)` 计数确保子查询内的关键词不算新语句。
- 跳过字符串/注释：维护 `inString` / `inBlockComment` / `inLineComment` 状态。
- 性能：大文件时只扫描语句范围（通常 < 100 行），而非全文。

```csharp
public class SyntaxLocator

    AfterJoinKeyword,           // JOIN 后
    AfterJoinOnKeyword,         // ON 后

    AfterHavingKeyword,         // HAVING 后
    AfterOrderByKeyword,        // ORDER BY 后

    AfterSetOperationKeyword,   // UNION/EXCEPT/INTERSECT
    AfterTopKeyword,            // TOP(n) 括号内

    // ===== INSERT 特有 =====

    InsertColumnListPosition,   // INSERT(列名列表) 括号内

    UpdateSetPosition,          // SET 后
    UpdateSetColumnAssignment,  // SET 列=后
    UpdateFromTablePosition,    // UPDATE 附加 FROM

    // ===== DELETE 特有 =====
    DeleteTablePosition,        // DELETE 后（表名）

    // ===== EXEC 特有 =====

```

**定位算法（伪代码）**：

```
function Locate(statement, cursorOffset, statementType):
    // Step 1: 解析语句中的关键词序列及其位置
    keywords = ExtractKeywordsOrdered(statement)
    // keywords = [{word: SELECT, pos: 0}, {word: FROM, pos: 45}, {word: WHERE, pos: 80}]

    // Step 2: 找到光标前后的两个关键词
    prevKeyword = find keyword where pos <= cursorOffset (nearest before)
    nextKeyword = find keyword where pos >= cursorOffset (nearest after)

    // Step 3: 根据前后关键词 + 语句类型判定 SyntaxNode
    if cursorOffset within string/comment:
        return InCommentOrString

    if prevKeyword is null:
        return StatementStart

    switch (prevKeyword.word):
        "SELECT":
            if no next keyword or nextKeyword.word in ("FROM", "INTO", "WHERE"):
                // SELECT 与列区之间
                keywordAfterSelect = text between "SELECT" and next possible
                if ImmediatelyAfterKeyword(statement, cursorOffset, "SELECT"):
                    return AfterSelectKeyword
                else:
                    return SelectColumnArea
        "FROM":
            return AfterFromKeyword
        "JOIN", "INNER JOIN", "LEFT JOIN", "RIGHT JOIN", "CROSS JOIN", "FULL JOIN":
            // 检查是否在 ON 之后
            if has ON keyword between prevKeyword and cursor:
                return AfterJoinOnKeyword
            return AfterJoinKeyword
        "WHERE":
            return AfterWhereKeyword
        "AND", "OR":
            return AfterAndOrKeyword
        "SET":
            return UpdateSetPosition
        "ORDER BY":
            return AfterOrderByKeyword
        "GROUP BY":
            return AfterGroupByKeyword
        "HAVING":
            return AfterHavingKeyword
        "INSERT":
            if immediately followed by "INTO":
                return InsertIntoTablePosition
        "INTO":
            return InsertIntoTablePosition
        "VALUES":
            return InsertValuesPosition
        "EXEC":
            return ExecPosition
        "UNION", "EXCEPT", "INTERSECT":
            return AfterSetOperationKeyword
        ...

    // Step 4: 点号检测（在关键词判定之上，优先级更高）
    charBeforeCursor = statement[cursorOffset - 1]
    if charBeforeCursor == '.':
        wordBeforeDot = extract word before '.'
        if wordBeforeDot is a known alias or table name:
            return AfterDotNotation
        if wordBeforeDot is a known database name:
            return CrossDbContextPrompt

    // Step 5: 跨库检测
    textBeforeCursor = statement[0:cursorOffset]
    if textBeforeCursor matches "[DBName]." or "DBName." pattern:
        return CrossDbContextPrompt

    return ExpressionPosition  // 兜底
```

**关键设计决策**：
- 关键词提取：通过正则 `\b(SELECT|FROM|WHERE|...)\b` 获取有序列表，时间 O(n) 一次扫描完成。
- 括号栈：跳过子查询内部的关键词（不干扰外层判定）。
- `AfterDotNotation` 优先级最高，因为它对应的点号触发是用户最明确的操作。

**实现逻辑**（核心 switch）：

```csharp
public List<CompletionCandidate> GetCandidates(SyntaxNode node, ...)
{
    switch (node)
    {
        case StatementStart:
        case AfterSelectKeyword:
            return GetKeywordsAndTemplates(filterText)
                .Concat(GetFieldCandidates(node, ...))
                .ToList();

        case SelectColumnArea:
        case AfterWhereKeyword:
        case AfterAndOrKeyword:
        case SearchConditionPosition:
            return GetFieldCandidates(node, filterText, hasDotPrefix: false);

        case AfterDotNotation:  // 别名.
            return GetFieldCandidates(node, filterText, hasDotPrefix: true);

        case AfterFromKeyword:
        case AfterJoinKeyword:
        case TableNamePosition:
        case InsertIntoTablePosition:
        case UpdateTablePosition:
        case DeleteTablePosition:
            return GetTableCandidates(filterText, connectedDb);  // 含跨库引导

        case CrossDbContextPrompt:
            return GetCrossDbCandidates(filterText, connectedDb);

        case AfterExec:
            return GetSpAndFunctionCandidates(filterText, connectedDb);

        case UpdateSetPosition:
            var table = _parser.GetUpdateTargetTable(currentStatement);
            return GetFieldCandidates(table, filterText, hasDotPrefix: false);

        case InsertColumnListPosition:
            var insertTable = _parser.GetInsertTargetTable(currentStatement);
            return GetFieldCandidates(insertTable, filterText, hasDotPrefix: true);

        case InsertTableAfterInsertInto:
            return GetInsertExpandCandidate(currentStatement);  // 特殊：只有一个候选"展开"

        case AfterOrderByKeyword:
            return GetColumnAliasCandidates(currentStatement)
                .Concat(GetFieldCandidates(...))
                .Concat(GetKeywords("ASC", "DESC"))
                .ToList();

        case AfterJoinOnKeyword:
            var joinTables = _parser.GetJoinTables(currentStatement);
            return GetFieldCandidates(joinTables, filterText, hasDotPrefix: true);
            // 多个表的字段都提示，用别名前缀区分

        case InCommentOrString:
            return new List<CompletionCandidate>();  // 空列表，不展示

        default:
            return GetKeywordsAndTemplates(filterText);
    }
}
```

**字段候选生成**（含来源表标注 + 前缀插入）：

```csharp
private List<CompletionCandidate> GetFieldCandidates(SyntaxNode node, string filter, bool hasDotPrefix)
{
    var (aliasMap, bareTables, subqueryAliases) = _parser.Parse(currentStatement);
    var allSources = aliasMap.Concat(bareTables).Select(x => new SourceInfo
    {
        Alias = x.Key,
        PhysicalName = x.Value.physicalTable,
        IsTempTable = x.Value.isTempTable,
        Type = SourceType.Table
    }).ToList();

    // 添加子查询别名来源
    foreach (var sq in subqueryAliases)
    {
        allSources.Add(new SourceInfo
        {
            Alias = sq.Alias,
            Type = SourceType.Subquery,
            SubqueryColumns = sq.Columns
        });
    }

    if (allSources.Count == 0) return empty;

    var candidates = new List<CompletionCandidate>();
    bool isMultiTable = allSources.Count > 1;
    bool isDotTrigger = (node == AfterDotNotation) || hasDotPrefix;

    foreach (var source in allSources)
    {
        List<string> columns;

        switch (source.Type)
        {
            case SourceType.Table when source.IsTempTable:
                // 临时表：字段不可查询，但在别名映射中可见
                candidates.Add(new CompletionCandidate
                {
                    DisplayText =$"{source.Alias}.[#临时表#]",
                    FilterText = source.Alias,
                    InsertText =$"{source.Alias}.",
                    ItemType = CompletionItemType.Table,
                    MatchScore = -1  // 排在最后
                });
                continue;

            case SourceType.Subquery:
                // 子查询输出列
                if (source.HasStarSelect)
                {
                    // SELECT * → 尝试展开为对应物理表
                    columns = ExpandStarSelect(source, aliasMap, bareTables);
                }
                else
                {
                    columns = source.SubqueryColumns;
                }
                break;

            default:
                // 物理表：从缓存查询
                var dbColumns = _cache.GetTableColumns(source.PhysicalName, filter);
                if (dbColumns == null) continue;
                columns = dbColumns.Select(c => c.Name).ToList();
                break;
        }

        foreach (var colName in columns)
        {
            string prefix = isMultiTable && !isDotTrigger
                ? $"{source.Alias}."  // 多表 → 带 "别名.字段"
                : "";
            string display = isMultiTable && !isDotTrigger
                ? $"{source.Alias}.[{colName}]"
                : colName;
            string insert = prefix + colName;

            candidates.Add(new CompletionCandidate
            {
                DisplayText = display,
                FilterText = colName,
                InsertText = insert,
                ItemType = CompletionItemType.Field,
            });
        }
    }

    return SortCandidates(candidates, filter);
}
```

**别名解析正则**（强化版）：

```csharp
// 覆盖所有别名定义格式：
// FROM table [AS] alias
// FROM [schema].[table] alias
// FROM [db].[schema].[table] alias
// db.schema.table alias
// JOIN table alias ON ...
// INNER/LEFT/RIGHT/CROSS/FULL JOIN table alias
private static readonly Regex AliasPattern = new Regex(
    @"\b(?:FROM|JOIN)\s+"                          // FROM 或 JOIN
    + @"(?:\[?\w+\]?\.(?:\[?\w+\]?\.)?)?"          // 可选的 [DB].[Schema]. 前缀
    + @"\[?(\w+)\]?"                                 // 表名（捕获组1）
    + @"(?:\s+AS)?\s+(\w+)"                         // 可选的 AS + 别名（捕获组2）
    + @"(?=\s+(?:ON|INNER|LEFT|RIGHT|CROSS|FULL|WHERE|$))",  // 紧跟 ON 或另一JOIN或语句结束
    RegexOptions.IgnoreCase | RegexOptions.Compiled);

// 裸表（无别名）检测正则：
private static readonly Regex BareTablePattern = new Regex(
    @"\b(?:FROM|JOIN)\s+"                           // FROM 或 JOIN
    + @"(?:\[?\w+\]?\.(?:\[?\w+\]?\.)?)?"          // 可选的跨库前缀
    + @"\[?(\w+)\]?"                                 // 表名（捕获组1）
    + @"(?:\s+WITH\s*\([^)]*\))?"                   // 可选的 WITH()
    + @"(?!\s+(?:AS\s+)?\w+)"                       // 后面不是别名（无别名的裸表）
    + @"(?=\s+(?:ON|WHERE|INNER|LEFT|RIGHT|CROSS|FULL|,|$))",
    RegexOptions.IgnoreCase | RegexOptions.Compiled);
```

**临时表/子查询别名识别**：
- 临时表（`#T1`、`#T2`、`@tableVariable`）：仍解析为合法别名纳入 `aliasMap`，但标记 `IsTempTable = true`
- 子查询别名（`(SELECT ... ) L`）：通过括号栈匹配定位 SELECT 列表，解析输出列作为"虚拟表字段"

```csharp
// 子查询别名检测：匹配 (SELECT ... ) alias 模式
private static readonly Regex SubqueryAliasPattern = new Regex(
    @"\(\s*SELECT\s+(.+?)\s+FROM\s+.*?\)\s+(?:AS\s+)?(\w+)",
    RegexOptions.IgnoreCase | RegexOptions.Compiled | RegexOptions.Singleline);

// 子查询输出列提取：从 SELECT 列表提取列表达式
private static readonly Regex SelectColumnPattern = new Regex(
    @"(\w+(?:\.\w+)?)(?:\s+(?:AS\s+)?(\w+))?",
    RegexOptions.IgnoreCase | RegexOptions.Compiled);
```

**Parse 方法扩展**：

```csharp
public (AliasMap aliases, List<BareTable> bareTables, List<SubqueryAlias> subqueryAliases) Parse(string statementText)
{
    var aliases = new AliasMap();
    var bareTables = new List<BareTable>();
    var subqueryAliases = new List<SubqueryAlias>();

    // 1. 解析显式别名（FROM/JOIN Table alias）
    foreach (Match m in AliasPattern.Matches(statementText))
    {
        string tableName = m.Groups[1].Value;
        string alias = m.Groups[2].Value;
        aliases[alias] = (tableName, null, isTempTable: tableName.StartsWith("#") || tableName.StartsWith("@"));
    }

    // 2. 解析子查询别名 (SELECT ... ) L
    foreach (Match m in SubqueryAliasPattern.Matches(statementText))
    {
        string selectBody = m.Groups[1].Value.Trim(); // 子查询的 SELECT 列表内容
        string alias = m.Groups[2].Value;             // 子查询别名

        var columns = ExtractSelectColumns(selectBody);
        subqueryAliases.Add(new SubqueryAlias { Alias = alias, Columns = columns });
    }

    // 3. 解析裸表（无别名的 FROM/JOIN 表）
    foreach (Match m in BareTablePattern.Matches(statementText))
    {
        string tableName = m.Groups[1].Value;
        if (!tableName.StartsWith("#") && !tableName.StartsWith("@"))
        {
            bareTables.Add(new BareTable { DisplayName = tableName, PhysicalName = tableName });
        }
    }

    return (aliases, bareTables, subqueryAliases);
}

/// <summary>
/// 从子查询 SELECT 列表中提取输出列。
/// 处理：SELECT col1, t.col2, expr AS alias, *
/// </summary>
private List<string> ExtractSelectColumns(string selectBody)
{
    var columns = new List<string>();
    // 按逗号分割，注意跳过字符串和括号内的逗号
    foreach (var part in SplitByTopLevelComma(selectBody))
    {
        var trimmed = part.Trim();
        if (trimmed == "*")
        {
            // SELECT * → 无法确定列，标记为"展开模式"
            columns.Add("*");
            continue;
        }

        // 匹配 [别名.]列名 [AS] 别名 模式
        var m = SelectColumnPattern.Match(trimmed);
        if (m.Success)
        {
            // 优先使用 AS 别名，否则使用列名
            string colName = m.Groups[2].Success ? m.Groups[2].Value : m.Groups[1].Value;
            columns.Add(colName);
        }
        // 复杂表达式（如 CAST、函数）跳过——可使用名字的后两个组分段作为别名
    }
    return columns;
}
```

**SubqueryAlias 数据结构**：

```csharp
public class SubqueryAlias
{
    public string Alias { get; set; }
    public List<string> Columns { get; set; }  // 输出列名列表
    public bool HasStarSelect => Columns.Contains("*");  // 是否 SELECT *
}
```

**字段获取策略（临时表/子查询的处理）**：

| 来源类型 | 字段获取方式 | 候选展示 |
|---------|-------------|---------|
| 物理表（含跨库） | `_cache.GetTableColumns(物理表名)` | 正常字段列表 |
| 临时表 `#T1` | 缓存不可用 | 标记为"临时表"，候选显示 `仅表名，字段不可用` |
| 子查询别名 `(SELECT ...) L` | `ExtractSelectColumns` 推导 | 推导出的列名列表（基础场景：`SELECT col1,col2`） |
| 子查询 `SELECT *` | 展开为对应物理表的全部列 | 对应物理表的字段 |

> **重要限制**：子查询 `SELECT *` 的展开只在 FROM 子句为单表（且不是子查询/表值函数）时可用。如果子查询的 FROM 也是多表 JOIN，则 `*` 无法准确解析，标记为 HasStarSelect=true 但展开为"无法确定"的空列表（候选列表中仅显示 `L.[* 无法展开]` 占位项）。

## 5. INSERT 字段展开实现

### 5.1 触发时机

在 `InsertTableAfterInsertInto` 语法节点检测到以下条件时触发：

```
INSERT INTO [dbo].[BD_CF_EXTEND_Setting]█
                                        ↑ 光标在此，且后面没有 "(" 或 "VALUES"
```

### 5.2 实现逻辑

```csharp
// 在 CompletionDispatcher.GetCandidates 中：
case InsertTableAfterInsertInto:
{
    var insertTable = _parser.GetInsertTargetTable(currentStatement);
    if (insertTable == null) return empty;

    var columns = _cache.GetTableColumns(insertTable, "");
    if (columns == null || columns.Count == 0)
    {
        // 无缓存 → 轻提示，不展开
        return new List<CompletionCandidate>();  // 触发空候选 → 自动 HidePopup
    }

    var colList = string.Join(",", columns.Select(c => $"[{c.Name}]"));
    var expandedText = $"({colList}) VALUES (...)";

    // 返回一个特殊候选，选中后执行插入操作
    return new List<CompletionCandidate>
    {
        new CompletionCandidate
        {
            DisplayText = $"↪ 展开字段 ({columns.Count} 列)",
            InsertText = expandedText,
            ItemType = CompletionItemType.SpecialAction,
        }
    };
}
```

**幂等检测**：在分发前检查 `statementText` 中表名后是否已有 `(` 或 `VALUES`，如有则返回空候选（不触发）。

## 6. 跨库逐层引导实现

### 6.1 检测逻辑

在 `SyntaxLocator.Locate()` 中，当判定为 `TableNamePosition` 后，额外检查：

```csharp
if (node == TableNamePosition || node == AfterFromKeyword || ...)
{
    var textBeforeCursor = statement.Substring(0, cursorOffset);
    var crossDbMatch = CrossDbPattern.Match(textBeforeCursor);
    if (crossDbMatch.Success)
    {
        int dotCount = count dots after last keyword;
        switch (dotCount)
        {
            case 0: node = CrossDbContextPrompt; dbLevel = 0; break;  // 提示 DB
            case 1: node = CrossDbContextPrompt; dbLevel = 1; break;  // 提示 Schema
            case 2: node = CrossDbContextPrompt; dbLevel = 2; break;  // 提示 Table
        }
    }
}
```

### 6.2 候选生成

```csharp
private List<CompletionCandidate> GetCrossDbCandidates(string filter, string connectedDb, int dbLevel)
{
    switch (dbLevel)
    {
        case 0:  // 空 → 提示所有缓存数据库 + 当前库表
            var dbCandidates = _cache.GetDatabaseCandidates();
            var localTables = _cache.GetTableCandidates(connectedDb, filter);
            return dbCandidates.Concat(localTables).ToList();

        case 1:  // [DBName]. → 提示 Schema
            return _cache.GetSchemaCandidatesForDb(dbName, filter);

        case 2:  // [DBName].[Schema]. → 提示 Table/View/Function
            return _cache.GetObjectCandidates(dbName, schema, filter);
    }
}
```
