# 02 - SQL 格式化系统

## 一、功能概述

SQL Prompt 的格式化系统是其三大核心功能之一，通过**样式（Style）**机制提供对 SQL 代码格式的精细控制。格式化仅改变空白字符（换行、制表符、空格），**不改变代码语义**。

---

## 二、功能细节

### 2.1 格式化选项体系（155 个选项）

SQL Prompt 将格式化选项分为 **5 大类 16 个子类别**：

#### Global（全局）
| 子类 | 控制内容 |
|------|---------|
| Whitespace | 空格、制表符、换行符处理 |
| Lists | 列表项排列方式（如逗号位置） |
| Parentheses | 括号换行与间距 |
| Casing | 关键字、函数、类型的大小写 |

#### Statements（语句）
| 子类 | 控制内容 |
|------|---------|
| Data | DML 语句格式化 |
| Schema | DDL 语句格式化 |
| Control Flow | IF/WHILE/TRY-CATCH 等布局 |
| CTE | 公用表表达式格式化 |
| Variables | 变量声明格式化 |

#### Clauses（子句）
| 子类 | 控制内容 |
|------|---------|
| Join | JOIN/ON 子句格式 |
| Insert | INSERT 列列表和值布局 |

#### Expressions（表达式）
| 子类 | 控制内容 |
|------|---------|
| Function Calls | 函数调用格式 |
| Case | CASE 表达式布局 |
| In | IN 子句格式 |
| Values | VALUES 表达式格式 |
| Operators | 运算符间距 |

### 2.2 样式管理

| 样式类型 | 说明 |
|----------|------|
| Redgate 内置样式 | 开箱即用的预设风格 |
| 用户自定义样式 | 基于现有样式复制并修改 |

**样式文件格式**：
- v10.5.0 之前：`.sqlpromptstylev2` (XML)
- v10.5.0 及之后：`.json`

**操作方式**：
- 通过 `SQL Prompt > Edit Formatting Styles` 进入样式编辑器
- 创建、复制、编辑、删除样式
- 设置当前活动样式（Active Style）
- 支持对特定代码块**禁用格式化**（通过注释方式）
- 支持 **Unformat** 操作，移除所有格式化空白

### 2.3 团队共享机制

```
共享文件夹方案：
  ┌────────┐   ┌────────┐   ┌────────┐
  │ 用户A  │   │ 用户B  │   │ 用户C  │
  │ Style  │   │ Style  │   │ Style  │
  │ Folder │   │ Folder │   │ Folder │
  └───┬────┘   └───┬────┘   └───┬────┘
      │             │             │
      └──────┬──────┴──────┬──────┘
             │             │
        ┌────┴─────────────┴────┐
        │    共享存储            │
        │  (网络共享/OneDrive)   │
        │  存放 .json 样式文件    │
        └────────────────────────┘
```

**操作流程**：
1. 主用户复制样式文件到共享文件夹
2. 所有成员将 `Style folder` 指向同一共享路径
3. 自动加载共享文件夹内所有样式文件
4. 更新后重新加载即可获取最新版本

### 2.4 格式化触发方式

| 触发方式 | 操作 |
|----------|------|
| 手动格式化 | `Ctrl+K, Ctrl+Y` 或右键 → Format SQL |
| 大小写选项 | `Ctrl+B, Ctrl+U` 单独应用大小写规则 |
| 自动附带操作 | 格式化时可自动附带：插入分号、展开通配符、限定对象名、添加/移除方括号 |

### 2.5 缺失功能（vs dbForge SQL Complete）

| 缺失功能 | 说明 |
|----------|------|
| 粘贴时自动格式化 | dbForge 支持粘贴 SQL 时自动应用格式 |
| 批量文件/目录格式化 | dbForge 支持对文件/目录进行批量格式化 |
| 分隔符触发格式化 | dbForge 支持遇到特定字符时自动格式化 |
| 命令行格式化 | dbForge 支持通过命令行进行格式化操作 |

## 三、技术原理推测

### 3.1 格式化引擎架构

```
┌─────────────────────────────────────────┐
│           格式化引擎                       │
├─────────────────────────────────────────┤
│ 输入：SQL 文本 + 样式配置 (.json)         │
│   ↓                                     │
│ 1. T-SQL 解析 → 生成 AST + Token 流      │
│   ↓                                     │
│ 2. Token 遍历 → 在每个 Token 间应用格式规则│
│   ↓                                     │
│ 3. 规则查找：                            │
│    - Token 类型 → 对应的大类/子类          │
│    - 样式配置 → 具体的格式选项值            │
│   ↓                                     │
│ 4. 输出：重新拼接格式化的 SQL 文本         │
└─────────────────────────────────────────┘
```

### 3.2 格式化规则的实现方式

每个格式化规则本质上是一个**条件判断 + 输出变换**的函数：

```
规则示例："关键字大写"
  条件: Token.Type == KEYWORD
  变换: Token.Text → Token.Text.ToUpper()

规则示例："逗号前置换行"
  条件: Token.Type == COMMA
  变换: InsertNewlineBefore(token)
```

### 3.3 样式文件设计要点

从 SQL Prompt 的样式管理可以借鉴以下设计：

```json
{
  "name": "Team Standard",
  "version": "2.0",
  "rules": {
    "global.casing.keywords": "UPPER",
    "global.casing.datatypes": "UPPER",
    "global.whitespace.indent": "Tab",
    "statements.select.columns": "EachOnNewLine",
    "clauses.join.position": "NewLine",
    "expressions.case.format": "IndentBranches"
  }
}
```

## 四、用户体验亮点

1. **可视化编辑器**：样式编辑器提供实时预览，修改即可看到效果
2. **非侵入式**：格式化不影响代码语义，可安全使用
3. **局部豁免**：支持禁用特定代码块的格式化，保证特殊格式需求
4. **Unformat 能力**：可以移除所有格式化回到原始状态

## 五、可实现的借鉴方案

### 5.1 技术路线

| 步骤 | 内容 | 关键点 |
|------|------|--------|
| 1 | 实现格式化选项模型 | JSON 格式配置文件，树状层级结构 |
| 2 | 实现 T-SQL Tokenizer | 将 SQL 文本拆分为 Token 流 |
| 3 | 实现规则引擎 | 将 Token 类型映射到规则处理函数 |
| 4 | 实现样式编辑器 | UI 界面，实时预览 |
| 5 | 实现团队共享 | 文件系统共享或配置中心 |

### 5.2 关键挑战

| 挑战 | 应对策略 |
|------|---------|
| **规则冲突** | 定义规则优先级，后执行的规则覆盖前一个 |
| **注释保留** | Tokenizer 需要保留注释位置，不在注释区域应用格式 |
| **字符串内文本** | 不格式化 SQL 字符串字面量内的内容 |
| **性能** | 对大文件（数千行 SQL）需要优化 Token 遍历 |

### 5.3 最小可行实现

```
阶段1（核心）：基础格式化
  - 关键字大小写转换
  - 基础缩进（SELECT/FROM/WHERE 对齐）
  - INNER JOIN 换行

阶段2（完善）：全面规则
  - 所有 155 个选项的规则覆盖
  - 样式文件导入/导出
  - 格式化预览

阶段3（高级）：团队协作
  - 共享文件夹支持
  - 粘贴时自动格式化
  - 批量文件格式化
```
