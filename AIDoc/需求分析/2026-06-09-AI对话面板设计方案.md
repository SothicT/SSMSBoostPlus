# AI 对话面板设计方案

> 日期：2026-06-09 | 状态：已实施

## 1. 需求概述

为 SSMSBoostPlus 构建内嵌于 SSMS 的可停靠 AI 聊天工具窗口，以 SQL 专家模式提供智能代码辅助。

## 2. 核心需求（按优先级排序）

| 优先级 | 需求 | 决策 |
|--------|------|------|
| P0 | **对话式 AI 面板** | 可停靠工具窗口（ToolWindow），类似 SSMS 解决方案资源管理器 |
| P1 | **深度上下文注入** | 自动感知编辑器选中 SQL，后续扩展 schema/索引 |
| P2 | **流式输出体验** | CodebuddyCliBridge 已支持 stream-json，后续 UI 对接 |
| P3 | **便捷触发方式** | 右键菜单、Ctrl+Shift+K 快捷键 |
| P4 | **Prompt 定制** | 后续扩展 |

## 3. 功能设计

### 3.1 面板形态

- **类型**：WPF UserControl 嵌入 ToolWindowPane
- **能力**：可拖拽、固定、自动隐藏，与编辑器长期并存
- **入口**：菜单 `SSMSBoost++ → 💬 AI 对话面板`，快捷键 `Ctrl+Shift+K`

### 3.2 交互模式

- **SQL 专家模式**：自动捕获编辑器选中文本作为每次对话的隐含上下文
- **多轮对话**：会话期间保留完整聊天历史（关闭 SSMS 后清空）
- **快捷指令按钮**：面板顶部 4 个预设按钮（📝建议 / 💬注释 / 🎨格式化 / ⚡性能分析）

### 3.3 应用方式

- AI 回答中的 SQL 代码块自动识别并生成 "📋 应用此修改" 按钮
- 点击 → 弹出 AIDiffDialog 对比对话框 → 用户确认 → 替换编辑器选中文本

### 3.4 会话管理

- 仅内存存储（ChatSessionService），关闭 SSMS 后自动清空
- 事件驱动 UI 刷新（MessageAdded / SessionCleared）

## 4. 技术方案

### 4.1 方案对比

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **方案一（采用）** | WPF UserControl 嵌入 ToolWindow | 与现有技术栈一致，无额外依赖 | 需从零构建聊天 UI |
| 方案二 | WebView2 嵌入 | UI 灵活，天然支持 Markdown/代码高亮 | 引入 WebView2 运行时依赖 |
| 方案三 | 扩展 AIDiffDialog | 改动最小 | 弹出式窗口，不可停靠 |

### 4.2 架构设计


### 4.3 数据流

```
用户输入问题 + Ctrl+Enter
  → AIChatControl.SendMessage()
  → SsmsEditorService.GetCodeAsync() 获取选中 SQL
  → ChatSessionService.AddMessage(User)
  → BridgeFactory.CreateBestAvailableBridgeAsync()
  → ICodebuddyBridge.ExecuteAsync(AIRequest)
  → AIResponse (Markdown)
  → 正则提取 SQL 代码块 → 生成 ChatAction
  → ChatSessionService.AddMessage(Assistant)
  → WPF 渲染消息 + 操作按钮
  → 用户点击"应用此修改"
  → AIDiffDialog(原始代码, AI建议代码)
  → 用户确认 → SsmsEditorService.ReplaceSelectionAsync()
```

### 4.4 关键设计决策

1. **模型放 Core 层**：ChatMessage/ChatRole/ChatAction 放在 Core 层，避免 SSMS ↔ AI 循环依赖
2. **ToolWindow 延迟初始化**：无参构造函数 + `InitializeContent()` 模式，符合 VS SDK 标准生命周期
3. **快捷指令复用**：快捷按钮调用现有 `CodeAnalysisService`（建议/注释/格式化/性能分析）
4. **自由对话**：通过 `PromptTemplateManager.GetSystemPrompt(Suggest)` + 用户 prompt 构建
5. **旧菜单并行**：旧菜单命令保留不变，快捷按钮与旧菜单双向并行

## 6. 错误处理

| 场景 | 处理方式 |
|------|---------|
| AI 未配置 | 消息气泡显示 "⚠️ AI 尚未配置" |
| 编辑器无选中代码 | 快捷按钮提示 "⚠️ 请先选中 SQL 代码" |
| Bridge 超时/失败 | 消息气泡显示错误信息 |
| CLI 不可用 | 自动回退 HTTP API（BridgeFactory） |
| 快捷指令异常 | 消息气泡显示异常信息 + 日志记录 |
