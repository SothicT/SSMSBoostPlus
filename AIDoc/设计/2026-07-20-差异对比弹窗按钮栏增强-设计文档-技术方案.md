# 版本差异对比弹窗·复制 SQL 按钮 技术方案

> 角色：Architect（主 Agent 兼任）｜阶段：技术设计（G3 门控前产物）
> 采用 Architect 轻量级技术方案格式 B（功能迭代）。
> 设计原则：最小化修改、复用既有模式、不触碰 DTE、不改动依赖链。

## 1. 变更概述
- 变更范围：仅 `src/SSMS/UI/VersionHistory/` 下的 `LocalHistoryDiffDialog.xaml` 与 `LocalHistoryDiffDialog.xaml.cs` 两个文件。
- 影响模块：版本历史差异对比弹窗（LocalHistoryDiffDialog）。
- 技术目标：在底部按钮栏（Row 3）新增【复制 SQL】按钮，将右侧历史脚本 `_historicalScript` 复制到剪贴板，并给出按钮内反馈。
- 依赖链影响：仅 SSMS 项目（net472）；Shared / Core / AI 不受影响，无新增程序集引用、无 PkgDef 变更。

## 2. 接口变更
- 无新增对外接口 / API / 命令。
- 新增 UI 事件处理方法（private，仅供 XAML 绑定）：
  - `CopySqlButton_Click(object sender, RoutedEventArgs e)`：执行剪贴板写入与反馈。
- 新增 XAML 元素：`CopySqlButton`（命名 `x:Name="CopySqlButton"`），绑定 `Click="CopySqlButton_Click"`。

## 3. 数据变更
- 无数据库、配置文件、缓存、注册表变更。
- 数据来源复用既有私有字段 `_historicalScript`（构造入参 `rightScript`）。
- UI 资源：复用既有 `PrimaryButton` 样式，不新增 Resource。

## 4. 详细实现设计

### 4.1 XAML 变更（LocalHistoryDiffDialog.xaml，Row 3 按钮栏）
在现有 `<StackPanel Orientation="Horizontal" HorizontalAlignment="Right">` 内、`CloseButton` 之前（其左侧）插入：
```xml
<Button x:Name="CopySqlButton" Content="复制 SQL"
        Style="{StaticResource PrimaryButton}"
        Width="100" Margin="0,0,8,0" Click="CopySqlButton_Click"/>
```
> 说明：右对齐、排在【关闭】左侧，与现状布局一致；`PrimaryButton` 蓝色实心样式，与【在编辑器中打开】同为主操作按钮。

### 4.2 代码 Behind 变更（LocalHistoryDiffDialog.xaml.cs）
1. 新增命名空间导入（当前文件未引用）：
   ```csharp
   using System.Windows.Threading; // DispatcherTimer
   ```
2. 禁用态初始化：在构造函数 `InitializeComponent()` 之后（与 `WordWrapButton.IsChecked = true;` 同处）补充：
   ```csharp
   CopySqlButton.IsEnabled = !string.IsNullOrEmpty(_historicalScript);
   ```
   （`_historicalScript` 已在构造函数开头赋值：`_historicalScript = rightScript ?? ""`）
3. 新增事件方法（置于 Action Buttons 区域，紧邻 `OpenInEditorButton_Click`）：
   ```csharp
   private void CopySqlButton_Click(object sender, RoutedEventArgs e)
   {
       if (string.IsNullOrEmpty(_historicalScript)) return;
       try
       {
           System.Windows.Clipboard.SetText(_historicalScript);
           CopySqlButton.Content = "✅ 已复制";
           var timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(2) };
           timer.Tick += (_, _) => { CopySqlButton.Content = "复制 SQL"; timer.Stop(); };
           timer.Start();
       }
       catch (Exception ex)
       {
           _logger.Error(ex, "[LocalHistory] 复制 SQL 到剪贴板失败");
           CopySqlButton.Content = "复制失败";
           var timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(2) };
           timer.Tick += (_, _) => { CopySqlButton.Content = "复制 SQL"; timer.Stop(); };
           timer.Start();
       }
   }
   ```

### 4.3 复用既有模式说明
- 剪贴板写入：与 `AIStreamResultDialog.CopyCodeButton_Click`、`LocalHistoryToolWindowControl`（Clipboard.SetText）同源，使用 `System.Windows.Clipboard.SetText`。
- 反馈模式：与 `AIStreamResultDialog` 一致的"按钮文案切换 + DispatcherTimer 2s 复原"自包含反馈（弹窗为独立模态 Window，无 StatusBar，故不沿用 `UpdateStatus`）。
- 空脚本保护：与 `OpenInEditorButton_Click` 的 `if (string.IsNullOrEmpty(_historicalScript))` 同源双保险（禁用态 + 点击内判空）。

## 5. 影响评估（兼容性）
- 既有行为：不修改 `OpenInEditorButton_Click`、`CloseButton_Click`、渲染、差异导航、同步滚动等任何逻辑；现有按钮功能与位置完全不变（满足 AC-004 回归）。
- 布局：仅增加一个宽度 100 的按钮，弹窗 Width=1100 足够容纳，不会触发换行或截断。
- 线程安全：Click 事件在 WPF UI 线程（STA）执行，`Clipboard.SetText` 与 `DispatcherTimer` 均可在该线程直接调用，无需 Invoke。
- 构建：SSMS 项目（net472）原生支持 `System.Windows.Clipboard` 与 `DispatcherTimer`，无新依赖。

  ```
- 测试门禁（提交前必须通过）：

  ```

- 手动验收清单：AC-001 复制成功且文案复原；AC-002 空脚本禁用；AC-003 剪贴板异常不崩溃并记录日志；AC-004 既有按钮行为不变。

## 7. 技术风险与缓解
| 风险 | 等级 | 缓解 |
|------|------|------|
| `DispatcherTimer` 命名空间未导入导致编译失败 | 低 | 方案已明确补 `using System.Windows.Threading;` |
| 剪贴板被其他进程锁定抛异常致弹窗崩溃 | 低 | `try/catch` 全包裹，异常仅改文案并记日志 |
| 误在模态对话框内调用 DTE 引发死锁 | 低 | 本次仅操作剪贴板，严格禁止 DTE 调用 |
| 布局拥挤/换行 | 低 | 新增单按钮宽度 100，弹窗宽度充足，右对齐排列 |

## 8. 研发注意事项
- 严格最小化修改：只动上述 2 个文件、3 处改动（XAML 加按钮、加 using、加方法、加禁用态）。
- 中文 UI 文案遵循项目命名规范（MenuText/ButtonText 用中文）。
- 不要为"复制当前/仅复制差异/导出"预留代码或注释开关（属后续迭代，避免本次范围膨胀）。
- 完成后执行构建 + 测试门禁，确保无回归。
