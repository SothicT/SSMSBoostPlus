本周主线围绕「版本历史」模块做体验与性能增强：修复了「在编辑器中打开」焦点劫持与版本历史页签永久加载中两类缺陷；落地差异点快速定位与对比页 ListView 虚拟化重构（解决长 SQL 截断与大脚本卡顿）；将历史版本列表查询改为按需懒加载以缓解 10s+ 加载慢；同时完善 Agent Team 协作体系、新增 SpecContext 规范上下文模型与 SDD 辅助脚本。

4. **性能与 UI 重构（对比页虚拟化）**：FlowDocument → ListView 虚拟化，解决长行截断与大脚本卡顿，新增自动换行 / 同步滚动。
5. **性能优化（列表懒加载）**：列表查询去除 sqlcommand 大字段，复制 / 差异按需懒加载，加载态遮罩 + 等待光标 + 取消重叠加载。
6. **新增功能（SpecContext 模型）**：AI 模块新增规范上下文模型。
7. **工程化（Agent Team / SDD）**：完善 Agent Team 协作体系定义，新增 SDD 辅助脚本。

### 2.1 🐞 Bug 修复：在编辑器中打开后主编辑器键盘失效（2026-07-16）
- 现象：LocalHistoryDiffDialog 点击「在编辑器中打开」后新文档创建但主编辑器键盘失效。
- 根因：`OpenInEditorButton_Click` 未 `Close()` 弹窗，模态 ShowDialog 残留、焦点被劫持。
- 修复（文件 `src/SSMS/UI/VersionHistory/LocalHistoryDiffDialog.xaml.cs`）：
  - finally 关闭弹窗：`DialogResult = success ? true : (bool?)null; Close();`
  - `EditPoint.Insert` → `EditPoint.ReplaceText`（性能 O(n) → O(1)）
  - DTE / ActiveDocument / 脚本为空容错
- 验证：`dotnet build` 0 错误；`dotnet test` 136/136 通过。
- 交付物：`AIDoc/问题修复/活跃/2026-07-16-001-在编辑器中打开-弹窗未关闭-焦点劫持.md`

### 已知风险

- **RC2 数据库索引缺失**：历史版本表缺支持索引 `(objectname, databasename, PostTime DESC, ID DESC) INCLUDE(...)`，每次列表查询全表扫描 + 排序；使用者无建索引权限，需另行向 DBA 申请。无索引时 F1/F3/F4 仅缓解，根因仍在。
- **G5 验收依赖真实 SSMS 环境**：虚拟化 / 大脚本性能（20000+ 行不崩溃、5000 行 <1s）需在真实环境或构造大脚本验证，沙盒无法运行 SSMS。
- **模态弹窗 + DTE 调用风险**：历史教训——WPF 模态弹窗内/未 Close 时调用 DTE 会焦点劫持或死锁，新功能须规避（复制 SQL 仅操作剪贴板、不碰 DTE）。
