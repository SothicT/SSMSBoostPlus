# 06 - 导航与历史记录

## 一、功能概述

SQL Prompt 提供的导航与历史记录功能旨在帮助开发者在多个查询窗口和数据库对象之间高效切换和定位，减少手动浏览对象资源管理器的时间。

---

## 二、功能细节

### 2.1 Tab History（标签页历史）

当打开多个查询标签页时，SQL Prompt 记录用户的标签页切换历史，方便快速回到之前操作的窗口。

| 特性 | 说明 |
|------|------|
| **快捷键** | `Ctrl+Q` 打开 Tab History |
| **历史记录** | 按时间顺序列出最近访问的标签页 |
| **快速切换** | 点击历史项即可切换到对应标签页 |
| **搜索过滤** | 支持按标签页名称搜索过滤 |

### 2.2 Tab Coloring（标签页着色）

| 功能 | 说明 |
|------|------|
| **按服务器着色** | 不同服务器连接的查询窗口使用不同颜色 |
| **按数据库着色** | 同一服务器的不同数据库使用不同颜色区分 |
| **自定义规则** | 支持自定义着色规则 |
| **快速识别** | 开发者可通过标签颜色快速识别当前连接的数据库环境 |

### 2.3 对象导航

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| **Go to Definition** | F12 | 跳转到对象的定义位置 |
| **Select in Object Explorer** | Ctrl+F12 | 快速在对象资源管理器中定位对象 |
| **Find Invalid Objects** | — | 查找引用不存在对象的代码 |
| **Summarize Script** | Ctrl+B, Ctrl+S | 生成脚本摘要信息 |
| **Identifier Occurrence Highlight** | — | 高亮标识符出现的所有位置 |

### 2.4 Command Palette（命令面板）

类似于 VS Code 的命令面板，提供统一的命令入口：
- 快速搜索并执行 SQL Prompt 的任何命令
- 无需记忆所有快捷键
- 按名称搜索功能

## 三、技术原理推测

### 3.1 Tab History 实现

```
┌──────────────────────────────────┐
│           Tab History             │
├──────────────────────────────────┤
│ 监听 SSMS 标签页切换事件           │
│   ↓                              │
│ 记录：时间戳 + 标签页标识 + 标题    │
│   ↓                              │
│ 维护一个 LIFO 栈（最近访问的排前面）│
│   ↓                              │
│ Ctrl+Q → 弹出历史列表 → 选择切换    │
└──────────────────────────────────┘
```

### 3.2 Tab Coloring 实现

- 读取当前查询窗口的**连接信息**（服务器名 + 数据库名）
- 根据预定义的着色规则匹配颜色
- 通过 SSMS 的标签页 API 设置标签颜色

```
连接信息 → 着色规则匹配 → 颜色分配 → 设置标签颜色
   ↓
con.ServerName → SERVER_RULES_MAP
con.DatabaseName → DB_RULES_MAP
```

### 3.3 对象导航实现

- **Go to Definition**：在已加载的 schema 缓存中查找对象定义
- **Select in Object Explorer**：调用 SSMS 的 Object Explorer API 定位对象节点
- **Identifier Occurrence Highlight**：在编辑器中查找当前标识符的所有出现位置并高亮

---

## 四、用户体验亮点

1. **标签着色**：视觉上快速区分生产环境/开发环境/测试环境的连接
2. **Tab History**：类似浏览器的前进后退，减少窗口管理的心智负担
3. **双向导航**：既可以从 SQL 代码跳到对象资源管理器，也可以反向查找

## 五、可实现的借鉴方案

### 5.1 技术路线

| 功能 | 实现方式 |
|------|---------|
| Tab History | 监听 VS Shell 的窗口切换事件，维护历史栈 |
| Tab Coloring | 获取连接信息 → 规则匹配 → 操作标签页 UI |
| Go to Definition | Schema 缓存查找 + 编辑器跳转 |
| Select in Object Explorer | SSMS Object Explorer 自动化 API |
| Command Palette | 文本输入框 + 命令过滤 + 执行 |
| Identifier Highlight | 编辑器文本搜索 + 高亮标记 |

### 5.2 最小可行实现

```
阶段1（基础）：
  - Tab History（核心需求）
  - Tab Coloring（按服务器）

阶段2（增强）：
  - Go to Definition
  - Identifier Occurrence Highlight
  - Select in Object Explorer

阶段3（高级）：
  - Command Palette
  - Find Invalid Objects
  - Summarize Script
```
