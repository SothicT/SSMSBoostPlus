# 差异点快速定位（Diff Navigation）— 竞品分析报告

---

## 一、分析目的与范围

- **背景**：SSMSBoostPlus 版本历史差异对比已支持行级+子词级高亮与同步滚动，但**缺少差异导航**（自动跳转/上一下一处切换/计数），相对 Redgate、ApexSQL 存在交互差距（产品分析文档第 303 行已标注 `差异导航 ❌ 未实现`）。
- **目的**：调研主流 SQL 版本管理与通用 diff 工具的差异导航能力，为「差异点快速定位」功能提供功能矩阵、体验对比与差异化建议。
- **范围**：差异导航相关能力（差异块跳转、首处自动定位、上一处/下一处、计数状态、忽略空白等），不涉及回滚、Git 集成等其它维度。
- **时间范围**：2026-07。

## 四、核心功能深度对比

### 4.1 导航触发与定位
- **Redgate / dbForge**：打开对比后默认停留在首处差异或提供"Next Difference"工具条；支持键盘快捷键（如 F8 / Shift+F8）逐处跳转，状态栏显示"Difference X of Y"。
- **VS Code Diff**：顶部 breadcrumb/状态栏显示 `X / Y`，`F7` / `Shift+F7` 跳转，且语法高亮 + 行内装饰清晰。
- **SSMSBoostPlus（本期）**：打开自动跳转首个差异（对齐 Redgate 体验），提供「上一个/下一个」按钮 + 「差异 X / Y」状态，当前行高亮。

### 4.2 计数与反馈
- 主流工具均在工具栏/状态栏常驻显示 `X / Y` 计数，SSMSBoostPlus 本期对齐此范式。

### 4.3 高亮策略
- 通用做法：当前差异行用强对比色（如蓝/橙边框或底色）区别于"已差异但未选中"的行（浅红/浅绿/浅黄）。SSMSBoostPlus 本期采用"当前差异点独立高亮色 + 切换还原原底色"策略，避免与差异底色混淆。

## 七、SWOT 分析（仅就差异导航能力）

| 优势 Strengths | 劣势 Weaknesses |
|----------------|----------------|
| 补齐后与主流拉平，且复用既有子词级精度 | 本期不含"忽略空白/注释"，长脚本未虚拟化 |

| 机会 Opportunities | 威胁 Threats |
|--------------------|--------------|
| 与"实时追踪"卖点结合，形成"实时+易查"闭环 | 竞品持续迭代，需尽快补齐以防差距固化 |
| 后续可加"差异块列表/缩略图"形成超越 | 用户已习惯竞品导航心智，补齐仅为"达标" |

## 八、差异化策略建议

1. **先达标再超越**：本期务必补齐"自动跳转 + 上/下导航 + 计数 + 高亮"四项基础能力，使差异对比交互矩阵该项从 ❌ 变 ✅（产品分析第 303 行差距闭环）。
2. **复用实时优势**：导航与既有"实时差异高亮/同步滚动"组合，强调"打开即定位、逐处秒查"，契合 DBA 急诊场景。
3. **后续增强路线**（不在本期）：a) 键盘快捷键（F8/Shift+F8）；b) 忽略空白/注释选项；c) 差异块缩略图列表（像 Beyond Compare 的"差异概览"）。这些在产品分析 M5 中已规划，可分期实施。
4. **不做过度设计**：三路合并、依赖检查等属回滚/对比高级能力，不在导航 PRD 范围，避免范围蔓延。

## 九、结论与行动建议

- **核心发现**：差异导航是 SSMSBoostPlus 与 Redgate/ApexSQL 在差异对比交互上的最大单项差距，且行业已形成稳定心智范式（自动跳转/上一下一处/计数/高亮），实现门槛低、收益高。
- **优先级建议**：**P0 落地基础四项**（自动跳转、上/下、计数、高亮），对应产品分析 V1.5 M5。
- **风险提示**：a) 技术侧需 Architect 评估超长脚本下 `BringIntoView` 定位可靠性（见 PRD 第八章技术可行性风险）；b) 防止范围蔓延到"忽略空白/三路合并"。
- **行动建议**：批准本 PRD 后进入 BA 需求规格 → Architect 技术方案（G3）→ Developer 编码 → Tester 验收。
