## 根因分析

**一句话根因**：`AxialStyleConnectionProvider.TryGetFromWindowCaption()` 方法中 4 处正则表达式的服务器名捕获组字符类 `[\w\.\\\-]+` 不包含 `(` 和 `)`，导致含括号的服务器名（如 `NC-Rainbow-MBD3MD2-P(10.32.136.89/91)`）无法完整匹配，正则逐级降级到"仅匹配服务器名"兜底分支，数据库名被硬编码为 `"master"`。

### 详细推理链

**步骤 1 — 正则匹配失败**：

窗口标题 `SQLQuery1.sql - NC-Rainbow-MBD3MD2-P(10.32.136.89/91).MBD3MD2_01 (TANZHENYANG (844))` 进入 `TryGetFromWindowCaption()` 后，依次尝试 4 个正则：

| 次序 | 正则意图 | 服务器名捕获组 | 匹配结果 |
|------|----------|---------------|----------|
| 1 | 完整格式 (含 SPID) | `[\w\.\\\-]+` | ❌ 在 `(` 处停止，无法消费 `(10.32.136.89/91)` |
| 2 | 无 SPID 格式 | `[\w\.\\\-]+` | ❌ 同上 |
| 3 | 最简 server.db | `[\w\.\\\-]+` | ❌ 同上 |
| 4 | 仅 server 兜底 | `[\w\.\\\-]+` | ✅ 匹配 `NC-Rainbow-MBD3MD2-P`，数据库硬编码 `"master"` |

**步骤 2 — 数据库信息丢失**：

兜底分支（第 178-184 行）执行：
```csharp
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\s*\(");
if (match.Success)
{
    string server = match.Groups[1].Value;  // "NC-Rainbow-MBD3MD2-P"
    return BuildConnectionInfo(server, "master", "", "", null, null);  // 数据库硬编码为 "master"
}
```

**步骤 3 — 下游影响**：

`RefreshForActiveWindowAsync`（第 614-622 行）收到 `Database=master`，调用 `LoadForObject(mesbaseBuilder.ConnectionString, null, "master")`，导致 `_databaseFilter` 被设为 `"master"` 而非正确的 `"MBD3MD2_01"`。页签连接信息显示 `NC-Rainbow-MBD3MD2-P/master`，用户看到服务器已切换但数据库显示为 `master`。

## 修复建议

### 方案一（推荐）：扩展正则字符类，支持括号

将 4 处正则的服务器名捕获组字符类从 `[\w\.\\\-]+` 扩展为 `[\w\.\\\-\(\)]+`。

**修改 1** — 第 136-138 行（主正则）：

```csharp
// 修改前:
var match = Regex.Match(caption,
    @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\.(\w+)\s*\((\S+)\s*\((\d+)\)\)",
    RegexOptions.IgnoreCase);

// 修改后:
var match = Regex.Match(caption,
    @"\s-\s+([\w\.\\\-\(\)]+(?:,\d+)?)\.(\w+)\s*\((\S+)\s*\((\d+)\)\)",
    RegexOptions.IgnoreCase);
```

**修改 2** — 第 153-154 行（无 SPID 正则）：

```csharp
// 修改前:
match = Regex.Match(caption,
    @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\.(\w+)\s*\((\S+)\)",

// 修改后:
match = Regex.Match(caption,
    @"\s-\s+([\w\.\\\-\(\)]+(?:,\d+)?)\.(\w+)\s*\((\S+)\)",
```

**修改 3** — 第 175 行（最简 server.db 正则）：

```csharp
// 修改前:
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\.(\w+)\s*\(");

// 修改后:
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-\(\)]+(?:,\d+)?)\.(\w+)\s*\(");
```

**修改 4** — 第 178 行（仅 server 兜底正则）：

```csharp
// 修改前:
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\s*\(");

// 修改后:
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-\(\)]+(?:,\d+)?)\s*\(");
```

修改后，`NC-Rainbow-MBD3MD2-P(10.32.136.89/91)` 会被完整捕获为服务器名，`MBD3MD2_01` 会被正确捕获为数据库名，最终解析结果将是 `Server=NC-Rainbow-MBD3MD2-P(10.32.136.89/91), DB=MBD3MD2_01`。

### 方案二（备选）：兜底分支中额外提取数据库名

仅修改第 178-184 行的兜底分支，在匹配到服务器名后，从标题中额外提取 `.数据库名` 部分：

```csharp
// 修改后:
match = Regex.Match(caption, @"\s-\s+([\w\.\\\-]+(?:,\d+)?)\s*\(");
if (match.Success)
{
    string server = match.Groups[1].Value;
    // 新增：尝试从标题中提取数据库名
    var dbMatch = Regex.Match(caption, @"\.(\w+)\s*\(");
    string db = dbMatch.Success ? dbMatch.Groups[1].Value : "master";
    return BuildConnectionInfo(server, db, "", "", null, null);
}
```

方案一更彻底，从源头修复所有正则，推荐方案一。
